Invocation and Command Line

In general, JKCEMU is started with the following command:

java -jar jkcemu.jar [arguments ...]

If necessary, the Java call and/or the name or path of the JKCEMU program file must be adapted.

If JKCEMU is called without arguments, the emulator starts and loads its settings from the "standard" profile. It therefore makes sense to save the most frequently used settings in this profile. If the profile does not exist (e.g. the first time), JKCEMU starts with default settings.

The emulator can also be started with a different profile. To do this, simply specify the name of the profile as an argument.

If the first argument begins with a minus sign, it is not interpreted as the name of a profile, but as an option. With an option, it is not the actual emulator that is invoked, but a different JKCEMU function. The table shows the possible options:

Note for Windows Users

Under Windows, the two programs java.exe and javaw.exe are available for invoking Java. With java.exe, the console output appears in the command prompt. With javaw.exe, on the other hand, the console output is lost. In return, however, no window that might be disruptive is opened for the console output. So if you call JKCEMU with one of the options -?, -h, --help, -v or --version, you must do so in the command prompt and with java.exe. In all other cases, i.e. when JKCEMU is to start as a window application, javaw.exe is recommended instead.

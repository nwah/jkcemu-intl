1. General

The emulator supports joysticks under the Windows and Linux operating systems. If the emulated system originally has joystick ports that are emulated by JKCEMU, these emulated joysticks can be operated with the joysticks connected to the computer running the emulator.

2. Joystick Emulation with Connected Joysticks

JKCEMU automatically connects the emulated joysticks in order to the connected joysticks, i.e., if two joysticks are emulated, emulated joystick 1 is connected to the first connected joystick and emulated joystick 2 to the second. If only one joystick is connected, it is connected to the first emulated joystick. The second emulated joystick then has no "real" joystick.

However, you can change the assignment between emulated joysticks and connected joysticks. To do so, in the emulator window, open the Extra menu and select the Joystick... menu item. The JKCEMU Joysticks window opens, in which you can connect and disconnect each emulated joystick to a connected joystick individually. This makes it possible, with only one joystick connected, to map it to only emulated joystick 1, or only to joystick 2, or to both at the same time. In the latter case, you then operate both emulated joysticks in parallel with the one connected joystick.

3. Joystick Emulation without Connected Joysticks

If you have no joysticks connected to the computer running the emulator, or if they are not supported, you can still use the joystick emulation. To do so, click the arrows and action buttons in the joystick window with the mouse.

4. Operating Emulated Joysticks with the Keyboard

The emulated joysticks can also be operated with the keyboard, without the joystick window needing to be open. Pressing the Alt key, or the Command key on a Mac, together with a cursor key, F1, F2 or Enter at the same time operates the first emulated joystick. The second emulated joystick is reached by also pressing the Shift key at the same time.

The four cursor keys are responsible for the directions, Enter and F1 for the first action button, and F2 for the second action button.

In the joystick window, pressing the Alt or Command key is not necessary in order to operate the emulated joysticks with the keyboard.

5. Action Buttons

JKCEMU simulates two action buttons per joystick. However, some of the emulated systems support only one action button. In that case, both simulated buttons have the same effect. Both of them trigger the one action button supported by the emulated system.

If you use joysticks connected to the computer running the emulator that have more than two action buttons, these are mapped in turn, alternating, to the two buttons simulated by JKCEMU. However, if the operating system running on the computer running the emulator, or the joystick driver used, reports the same number for all action buttons, then they logically all trigger the same action button simulated by JKCEMU as well.

Copying and Pasting Text in the Emulator

In the screen output of the emulated system, you can select text and copy it to the clipboard. On some systems, including those with a 7-segment display, this function is not available, however.

The Paste function pastes the text from the clipboard back into the screen output. But that is only apparently the case. In reality, this text is passed to the program running in the emulator by simulating a key press for each individual character to be inserted. Due to this principle, it takes a relatively long time. On some emulated systems, there is also the option of speeding up pasting by enabling a special option.

Because of the principle of simulating keystrokes, it can also happen that certain characters cannot be pasted. This is exactly the case when the emulated system does not have a key or key combination for it.

LLC1

The LLC1 is a home-built learning computer presented by Dr. Gerd Maudrich in 1985, whose construction plans were sold.

The concept of this computer is somewhat idiosyncratic. On the one hand, it has a 7-segment display and a hexadecimal keyboard. On the other hand, the original construction plans already include a module for screen output on a monitor or television. The corresponding alphanumeric keyboard could also be purchased as construction plans. You operate the monitor program with the hexadecimal keyboard, while the BASIC interpreter, also contained in ROM, is operated with the alphanumeric keyboard.

1. Emulated Hardware

  • 5 KByte ROM in the address range 0000-13FF
  • 25 KByte RAM in the address range 1400-1BFF
  • 15 KByte video RAM in the address range 1C00-1FFF
  • 8-digit 7-segment display
  • Hexadecimal keyboard with additional function keys
  • Alphanumeric keyboard
  • Alphanumeric screen

1.1. Hexadecimal Keyboard

The table shows how the keys of the LLC1 hexadecimal keyboard are mapped onto the keyboard of the computer running the emulator:
LLC1 keyKey in the emulatorMeaning
EIN M "Input": display/change memory cells
REG R display/change "registers"
ES S "single-step mode"
DL G or J "run through": start program
HP H enter "breakpoint"
ST X or Enter "start": complete input
0...90...9address/data input
A...F A...F or a...f address/data input

1.2. Alphanumeric Screen

The alphanumeric screen is shown in a separate window. This window opens automatically as soon as the relevant video RAM is written to. If you have closed the window and want to open it again, call up the menu item Extras → Secondary Display Unit... in the main window.

1.3. Alphanumeric Keyboard

The alphanumeric keyboard is linked to the alphanumeric screen, i.e., if you want to enter input with the alphanumeric keyboard, you must activate the window with the alphanumeric screen. If, on the other hand, the main window with the hexadecimal display is active, keyboard input results in actions on the emulated hexadecimal keyboard.

2. Software Contained in the ROM

  • Original monitor program
  • LLC1-BASIC V1.2

2.1. Notes on Operating the Monitor Program

Pressing one of the keys EIN (M), REG (R), ES (S), HP (H) and DL (G) takes you into one of the five modes. This also applies if you are already in a different mode. You can therefore switch between the modes at any time, as you like.

2.1.1. EIN: Input (Display/Change Memory Cells)

EIN (M) → <address> [ → <value> ] → ST (Enter)

Caution! Each time you press the ST (Enter) key, the address is incremented by one. To change the value at the first address, you must type the two-digit value directly after the four-digit address and only then press ST (Enter).

2.1.2. REG: Display/Change Registers

REG (R) → ST (Enter) → ST (Enter) → ...

Each time you press ST (Enter), the next register pair is shown, in the following order: SP, PC, IY, IX, HL, DE, BC, AF, HL', DE', BC' and AF'.

To change the register content, enter the new value and then press ST (Enter).

2.1.3. ES: Single Step

ES (S) → <address> → ST (Enter) → ...

The monitor program loads the registers and then executes the instruction at the specified address. It then halts again, and the register contents are saved.

2.1.4. HP: Set Breakpoint

HP (H) → <address> → ST (Enter) → ...

A breakpoint is set at the specified address, so that a program started with the DL mode halts there. The register contents are saved and can be viewed and changed with the REG mode.

The breakpoint is implemented using a restart instruction, which is written to the specified address. For this reason, the breakpoint can only be set in RAM and only on the first byte of a CPU instruction.

2.1.5. DL: Run Through (Start Program)

DL (G) → <address> → ST (Enter) → ...

The run through mode starts a program. The name refers to letting a program run through.

3. BASIC

The ROM contains a simple BASIC interpreter, which you can start at addresses 0800 (cold start) and 0803 (warm start). So, to start it for the first time, enter:
G 0 8 0 0 Enter

3.1. Saving a BASIC Program

JKCEMU offers special support for saving and loading BASIC programs. To save, please use the function Save BASIC Program... in the File menu and save the program as a Headersave file with the file type b.

3.2. Loading a BASIC Program

First load the BASIC program and then start the BASIC interpreter with a warm start.

3.3. Displaying a BASIC Program Located in Working Memory

Please use the menu item Open BASIC Program in Text Editor... in the File menu for this.

4. Miscellaneous

4.1. AutoInput

AutoInput performs automatic keystrokes only on the hexadecimal keyboard. The emulated alphanumeric keyboard cannot be operated with it.

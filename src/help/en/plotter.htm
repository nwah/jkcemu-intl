Plotter

For some of the computers emulated by JKCEMU, a plotter is also emulated. You can see the plotter output in a separate window, which you can open via the menu item Extras → Plotter.... There you also have the option to print the plotter output on paper, copy it as an image to the clipboard, or save it as an image file.

On a real plotter, the individual sheets of paper must be inserted manually. In JKCEMU you do this conceptually by invoking the menu item File → New Page in the plotter output window. You can also set the pen width, the pen color (foreground color), and the paper color (background color) in that window. When you save a profile (see Settings), these settings are saved along with it.

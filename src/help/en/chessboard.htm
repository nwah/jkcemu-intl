Chessboard

The chessboard window shows you the current chessboard layout, i.e. the layout that the computer has stored internally. This allows you to play chess without having to make the moves yourself on a separate chessboard.

You open the chessboard display in the main window via the menu Extras → Chessboard....

Entering a move via the chessboard window is not possible.

Caution! Switching sides in the chessboard window only changes the view, not the color you are playing. So if you want to play with the black pieces instead of the white ones, or vice versa, you must do so with the corresponding input in the chess program.

Caution! While the chess computer is thinking, it plays through various possible moves. Since it also temporarily changes its internal chessboard layout while doing so, you also see its "thoughts" in the chessboard window. The displayed game state is only valid, however, once the chess computer has finished thinking and shows its move on the 7-segment display.

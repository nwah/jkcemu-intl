Keyboard

The keyboard of the emulated system can contain keys that cannot be found on the keyboard of the computer running the emulator. Such keys are then mapped to other keys. The help page for the respective emulated system tells you whether, and if so how, such keys are mapped.

For some of the computers emulated by JKCEMU, a keyboard view is also available that recreates the original keyboard (menu Extras → Keyboard...). You can click the displayed keys with the mouse and thereby make all the inputs that are also possible on the original.

For some inputs, it may be necessary to press several keys at the same time (e.g. key combinations with the Control or Shift key). For this, it is necessary to also be able to press keys in such a way that they stay pressed after the mouse button is released. JKCEMU supports you in this by having the Control and Shift keys latch by default until you click the next key. This support can be switched off in the File menu. However, the corresponding menu item is only present if the emulated keyboard also contains Shift or Control keys.

Regardless of the behavior of the Shift or Control keys, any key can also be latched by clicking it while holding down the Ctrl key on the real keyboard, or by clicking with the middle or right mouse button.

For further convenience, the Shift key on the real keyboard is mapped directly to the keyboard view (if present), i.e., for input with Shift, you do not necessarily have to click the Shift key first, but can also press the Shift key on the real keyboard.

Loading and Saving BASIC Programs

Loading and saving BASIC programs requires a special procedure. For the usual BASIC interpreters of the emulated systems, JKCEMU offers dedicated functions. You will find them in the File menu.

  • 1. Loading a BASIC Program
  • 2. Saving a BASIC Program
  • 3. File Formats for BASIC Programs

1. Loading a BASIC Program

  1. Load the BASIC interpreter into the emulator's working memory (not relevant if the BASIC interpreter is already in ROM).
  2. Perform a cold start.
  3. Exit the BASIC interpreter, usually with BYE.
  4. Load the BASIC program into working memory like an ordinary file (see Load File).
    For this, the BASIC program must be saved in a file format that is also recognized as BASIC (see the section File Formats for BASIC Programs further below). If the BASIC program is loaded from a non-BASIC file, the system cells of the BASIC interpreter are not adjusted, which can lead to undesired effects, up to and including a crash of the entire BASIC interpreter.
  5. Perform a warm start of the BASIC interpreter.
  6. You can now start the BASIC program with RUN.
Caution! With some BASIC interpreters there are no problems if you omit steps 3 and 5, i.e. if you load the BASIC program while you are currently in the command loop of the BASIC interpreter. However, the interpreter must not be doing anything else at that moment, and must certainly not be running a BASIC program! In contrast, with AC1 Mini-BASIC, LLC1 BASIC, and Z1013 Tiny-BASIC you must always perform steps 3 and 5!

If the BASIC program is stored in a KCC or KC-TAP system file (KC-BASIC program) such that JKCEMU does not recognize this file as a BASIC program, you must proceed as follows: Extracting a KC-BASIC Program from a KCC/KC-TAP File.

2. Saving a BASIC Program

In the File menu, click on the item Save BASIC Program.... Depending on the emulated system, you may then be asked which BASIC interpreter is in use, so that JKCEMU knows in which address range to look for the BASIC program. The dialog for saving a file then appears (see Save File). The input fields for the address range to be saved are already filled in, and the file format for BASIC programs that matches the emulated system is already preselected.

Caution! In principle, you can save the BASIC program in any file format supported by JKCEMU, but using the wrong format (see the section File Formats for BASIC Programs further below) would cause problems when loading it later. In that case, the system cells of the BASIC interpreter are not adjusted, and as a result the BASIC program cannot be used within the interpreter. For this reason, you should always save a BASIC program in the file format preselected by JKCEMU.

A5105 (BIC, ALBA-PC 1505)

The educational computer A5105, often called simply the educational computer, BIC, or BIC A5105 for short, was developed by Robotron for the educational system of the GDR and introduced in the fall of 1989. As standard, the system consisted of the following components:
  • Basic computer unit (CGG) K1505
    • the actual computer with keyboard in a single unit
    • can also be used as a BASIC home computer with a separate power supply (connectors for cassette recorder and joysticks are present)
    • monitor connection only via RGB,
      a separate RF modulator is required for a TV connection
  • Floppy disk storage unit (DSE) K5651
    • floppy disk controller (FDC) with one floppy disk drive
    • CP/M-compatible operating system SCPX 1505 in ROM
    • network connection (BICLAN)
    • power supply, also used to power the basic computer unit
    • plugs directly onto the basic computer unit
  • Monitor K7222 (black/green)
    • Although the A5105 offers color output, it was usually shipped only with a black/green monitor.

Remaining stock of the A5105 was also sold as the ALBA-PC 1505. It consisted of the basic computer unit K1505, the power supply K0309, and the RF modulator 690034. An FDC module with a floppy disk drive was optionally available too.

1. Emulated Hardware

Emulated:
  • Basic unit
  • Printer
  • Two joysticks
  • Optional:
    • Floppy Disk Station
    • GIDE with up to two hard disks at I/O base address D0h
    • Two RAM floppies
    • K1520 sound card
    • KCNet-compatible network card at I/O base address C0h
    • USB port (Vinculum VDIP module) at I/O base addresses 2Ch and FCh

1.1.1. AutoInput

If you use the AutoInput function while the option Paste text by intercepting the system call is also activated, it can happen that the first character is not entered automatically. To prevent this, it is best to enter the control key Enter / Return before the first command.

1.2. Sound Generator / Sound Output

To hear the key click as well as the sound generator contained in the basic unit, you must activate the tone output in the Audio/Tape window, on the Sound Generator tab.

Caution! In the original, the data storage unit contains a loudspeaker that can be switched on and off via I/O address 70h. However, this does not switch off the sound at the audio/video connector. As far as tone output is concerned, JKCEMU emulates the audio/video connector, i.e. output to I/O address 70h has no effect in the emulator.

Note: The sound generator is always emulated at the original clock frequency, i.e. if you specify a different clock frequency in the settings, it only affects the emulation of the microprocessor, not the sound generator.

1.3. V24 Interface with Printer

A printer connected to the basic unit's V24 interface is emulated. Both this interface and the emulated V24 parameters correspond to the A5105's default settings, i.e. no special printer setting is necessary in the A5105 operating system.

1.4. Graphics Display Controller U82720

The graphics display controller (GDC) U82720 is only partially emulated. Functions such as ZOOM, PAN, and the drawing of graphical elements and figures are not implemented. The A5105's system software contained in ROM does not use these functions of the GDC. As a result, application programs that exclusively use the facilities provided by the operating system for outputting text and graphics should not be affected by this limitation.

RBASIC draws graphical elements such as circles, lines, and sprites itself, i.e. it calculates the pixel data in software and passes it on to the GDC. This works without any problems in the emulation. SCPX has no graphics functions and usually works only in text mode. This also works without any problems.

3. Included Floppy Disk Images

For A5105 emulation, JKCEMU includes the following floppy disk images:
  • RBASIC Disk with Images
  • RBASIC Program Disk
  • RBASIC System Disk
  • SCPX System Disk

To use the floppy disk images, emulation of the Floppy Disk Station must be activated.

3.1. RBASIC Disk with Images

This disk contains photos that were processed with the image editor included in JKCEMU and converted into the A5105 format. The images can be displayed as a slideshow. The RBASIC program for displaying the slideshow starts itself automatically, i.e. after inserting the disk into the Floppy Disk Station, you only need to trigger a RESET and the program starts.

If you want to start the slideshow manually, this is how:

  run "autoexec.bas"

It is also possible to display the images individually:

  run "viewscr.bas"

3.2. RBASIC Program Disk

The RBASIC Program Disk contains a selection of demonstration, game, and application programs. The programs are started with:

  run "program.bas"

In place of program.bas, the correct file name must be specified.

3.3. RBASIC System Disk

The RBASIC System Disk contained in the emulator largely corresponds in content to the original system disk and also contains, among other things, the BIC demonstration program. This is started as follows:

  run "bicdemo"

Furthermore, the image viewer program viewscr.bas can also be found on the disk.

3.4. SCPX System Disk

SCPX requires a writable disk when booting. Since the floppy disk images built into the emulator are not writable, the SCPX system disk should first be exported in the JKCEMU Floppy Disk Station window and the resulting image file then opened without write protection. For this reason, you will find the SCPX system disk only in the submenus Insert Different Floppy Disk and Export Floppy Disk.

However, you can also insert the SCPX system disk directly via the Insert Different Floppy Disk submenu and boot from it. In that case, though, an error message appears. You can dismiss it with a keypress, though, and still work with SCPX anyway.

The SCPX system disk appears as drive A: and also contains drivers for the two RAM floppies (RAFBIC20.COM and RAFBIC24.COM).

Caution! The disk also contains the empty file GO.COM. It is used to start a CP/M-compatible program residing in main memory. If GO is invoked without a program present in main memory, this causes a crash.

4. Miscellaneous

4.1. Opening BASIC Programs in the Text Editor

The menu item File → Open BASIC Program in Text Editor... is not active in the A5105 emulation, because the binary format of RBASIC programs is not documented and is therefore also not fully known. However, you can still open a BASIC program residing in main memory in the text editor by "printing" it with the command LLIST and then opening the print result in the text editor. You can reach the print result via the menu item Extra → Print Jobs... (see Printing).

4.2. Saving and Loading BASIC Programs

JKCEMU offers special support for saving and loading BASIC programs. To save, please use the function Save BASIC Program... in the File menu and save the respective program as a BASIC/RBASIC program file (*.bas). Alternatively, you can also save it as a Headersave file (*.z80) with file type B.

If you save a BASIC program in a different file format, JKCEMU will no longer recognize, when later loading the file, that it is a BASIC program, and will not adjust the system cells of the BASIC interpreter accordingly. The loaded program cannot then be used.

If you have activated emulation of the floppy disk module in the settings for the A5105, you can alternatively also save BASIC programs to an emulated disk using the RBASIC commands SAVE and LOAD, and load them from there again.

4.2.1. Saving BASIC Programs via the Emulated Cassette Interface

If you want to save a BASIC program via the emulated cassette interface, please do so at speed 1. The program name can be up to 6 characters long. In this example, the BASIC program is saved under the name prog:

  csave "prog",1

You can then read the program back in with:

  cload

or

  cload "prog"

4.3. Loading Files into Main Memory

In SCPX mode, the operating system automatically switches the ROM in and out cyclically. So that loading files into main memory using the emulator's functions works reliably despite this behavior, files are always loaded into RAM, even if it is not currently switched in.

4.4. Character Set

The A5105 contains a programmable character generator, which by default is filled with the old DOS character set (code page 437). If the character generator is reprogrammed by software, the emulator cannot know this. For this reason, when copying from the A5105's screen output, JKCEMU always converts the characters into the emulator computer's character set according to code page 437, regardless of how the character generator is actually programmed.

4.5. Size and Aspect Ratio of the Screen Output

The A5105 offers various screen resolutions. When switching between these (e.g. with the BASIC command screen 1 for the 80-character mode), the size of the emulator window and the aspect ratio also change. In the original, on the other hand, the size of the screen output area always stays the same. With the option Same window size in all screen modes you can adapt the behavior to match the original. However, the emulator window is then always large enough that the highest screen resolution can be displayed.

4.6. Pasting Text from the Clipboard

Pasting text from the clipboard is usually done by simulating, for each character to be pasted, the pressing of the corresponding key or key combination. This principle is quite slow. For the A5105, there is an option in the settings called Paste text by intercepting the system call. With this option, the emulator listens at the entry point for the CONIN system function. When this system function is called, JKCEMU checks whether a character should be pasted. If so, it writes the next character to be pasted into the corresponding processor register and simulates a RETURN instruction. If the operating system or the application program does not query the keyboard via the CONIN system function, pasting text will not work, and you will have to switch the option off.

Caution! If nothing happens when pasting text from the clipboard, the operating system is currently in a state that is unfavorable for keyboard input. In that case, press a key on the keyboard, ideally the key for the first character to be pasted, to "wake up" the operating system.

4.7. A5105 Image Files

The JKCEMU Image Viewer supports both reading and writing A5105 image files that correspond to the RBASIC graphics mode SCREEN 5 (320x200 pixels, 16 colors). To display them in the JKCEMU Image Viewer, the files must have the extension *.scr. Conversely, such image files can also be created with the Image Viewer. Loading and displaying such files on the A5105 is possible with the following short RBASIC program:

10 SCREEN 0:CLS
20 FILES "*.scr"
30 PRINT:INPUT "Bilddatei:";F$
40 IF INSTR(F$,".")=0 THEN F$=F$+".SCR"
50 SCREEN 5,0:CLS
60 BLOAD F$,S:PAUSE 50
70 IF INKEY$="" THEN 70
80 GOTO 10

The program displays the list of existing image files and asks for the name of the file to be loaded. The file name can also be entered without the extension .SCR.

An extended version of this program is included on the floppy disk images contained in the emulator, BIC A5105 RBASIC Disk with Images and BIC A5105 RBASIC System Disk. If you have inserted one of these two disks in the JKCEMU Floppy Disk Station window and are in RBASIC, you can start the program with:

  run "viewscr.bas"

Hübler/Evert-MC

Bernd Hübler and Klaus-Peter Evert developed a computer whose construction plans were published in 1984 in the magazine electronica 227/228. Since this computer has no name of its own, it is called the Hübler/Evert-MC in JKCEMU.

Notes on the Emulation

1. Emulated Hardware

  • 3 KByte ROM (F000h-FBFFh)
  • 1 KByte SRAM (FC00h-FFFFh)
  • 2 KByte video RAM (E800h-EFFFh)
  • 58 KByte DRAM (0000h-E7FFh)
  • CTC
  • 2 PIOs
Of the universal I/O board, only the CTC and the two PIOs are emulated. The SIO and the cassette recorder interface, as well as any hardware connected to the PIOs, are not emulated.

1.1. Printer

A printer is emulated by JKCEMU intercepting the operating system calls for print output and appending the data to the current print job. This function can be switched off in the Settings.

2. Software Contained in ROM

  • Monitor program version 2.1
In the monitor program, you can display a list of all commands with HELP. The list contains both the commands of the monitor program itself and those that may be found elsewhere in memory.

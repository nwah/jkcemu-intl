AutoLoad and AutoInput

AutoLoad and AutoInput are functions for bringing the respective emulated system into a user-defined initial state, and they are meant to increase convenience for the user.

After every emulated power-on or every RESET, AutoLoad automatically loads files into working memory (RAM). After every emulated power-on or every RESET, AutoInput automatically performs keyboard input. Both functions work independently of each other, but combine well. For example, you can use AutoLoad to load an executable program file and then use AutoInput to issue, after a short wait, the command to start the program.

AutoLoad and AutoInput are available for many, but not all, of the systems emulated by JKCEMU. For the supported systems, you will find the AutoLoad and AutoInput tabs in the respective settings. There you can create as many entries as you like, which are processed in order from top to bottom after the emulated power-on and after RESET. For each entry, you can also specify a time that JKCEMU waits before executing that entry.

The automatic keyboard input in AutoInput is performed using the function for pasting text into the emulator. Depending on the emulated system, this can take varying amounts of time.

Note: The hardest part of AutoLoad and AutoInput is getting the timing right. If in doubt, specify a somewhat longer pause, or, for AutoInput, split the input across several entries with corresponding pauses in between. The emulated system needs a certain amount of time to process the input.

Caution! AutoLoad and AutoInput are general-purpose functions and do not take into account the particular quirks of the respective emulated system. For example, with AutoLoad you can specify that files be loaded into an address range where there is no RAM at all. In that case, however, nothing will simply be loaded. Likewise, with AutoInput you can specify characters or control keys that cannot actually be entered on the emulated system (e.g. because of a hexadecimal keyboard). In that case, a corresponding message will appear while AutoInput is running.

Caution! For the control key Cursor Left / Backspace, AutoInput sends the code 08h to the emulated system, and for the key Cursor Right / Tab it sends the code 09h. Some systems treat the Cursor Left and Backspace keys, or the Cursor Right and Tab keys, differently. In such a case, which specific function is executed depends on the emulated system.

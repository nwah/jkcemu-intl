RAM Floppies

On the original hardware, some of the emulated systems have one or two RAM floppies. These are emulated as well.

JKCEMU gives you the option of accessing the data stored in the emulated RAM floppies directly, i.e. this data can be saved as an image file and loaded again. To do so, call up the menu item RAM Floppies... in the File menu of the emulator window.

In the Settings for the individual emulated systems on which RAM floppies are emulated, you can also specify image files that are loaded automatically. This is a particularly convenient way to have the RAM floppies pre-loaded with useful data at the start of a session.

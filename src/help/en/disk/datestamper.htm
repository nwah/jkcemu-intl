DateStamper

DateStamper is a method for storing timestamps for files in CP/M-compatible file systems. The individual timestamps are kept in the file !!!TIME&.DAT, which physically must be the first file on the floppy disk. For each file, the time of creation, the time of last access, and the time of last modification can be stored to the minute.

1. DateStamper Support in JKCEMU

JKCEMU optionally supports DateStamper in:
  • Creating an Image File Manually
  • Unpacking a CP/M Disk Image File
  • Mapping an Emulated Floppy Disk to a Directory


2. Structure of the Timestamp File

The timestamp file !!!TIME&.DAT contains 16-byte records, with each record assigned to a directory entry. The assignment is made in order, i.e. the first record in the timestamp file refers to the first directory entry, and so on. The file !!!TIME&.DAT is thus exactly half the size of the directory (which has 32 bytes per entry).

Each record in the timestamp file contains the five-byte timestamps for the time of creation, the time of last access, and the time of last modification, as well as a check byte.

A timestamp consists of five BCD-encoded bytes:
  1. Year (for 0...77 +2000, for 78...99 +1900)
  2. Month (1...12)
  3. Day (1...31)
  4. Hour (0...23)
  5. Minute (0...59)

If a timestamp contains invalid values, e.g. month or day equal to zero, this means the timestamp is not set.

With regard to the check byte, every eight records form a group. The check bytes of the first seven records of a group spell out the string !!!TIME. The check byte of the eighth record is the sum of all the preceding 127 bytes of the group.

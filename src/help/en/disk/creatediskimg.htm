Creating an Image File

1. Creating an Image File from a Floppy Disk or Other Volume

You can create a plain image file from a floppy disk or other volume, if a corresponding drive is present in or connected to the computer running the emulator and is supported by the operating system. For floppy disk drives, it is especially important that the physical floppy disk format (number of tracks, number of sectors per track, sector size) is supported. To create the image file, open the menu item Extras → Tools → Create Image File from Volume... in the main window.

Caution! Access to physical drives depends on various factors and therefore cannot be guaranteed on all platforms and operating system environments. Depending on the operating system and the type of volume, e.g. whether it is partitioned, JKCEMU may need to run under a user with special privileges (e.g. administrator). However, it is also possible that access to the volume is denied despite administrator privileges, or that the function is not available at all on your system.

2. Creating an Image File Manually

JKCEMU offers the option of manually creating disk image files that correspond to the CP/M 2.2 floppy disk format. You can find the tool for this in the main window in the menu Extras → Tools → Create CP/M-Compatible Disk Image Manually.... It can also be started as a standalone program without the emulator. To do this, specify the option --dc or --diskcreator on the command line when invoking JKCEMU.

The tool's window contains two subwindows, between which you can switch using the two tabs. In the first tab, you add the files that the image file is to contain. You do this using the menu item File → Add... or by drag&drop. Files that have been copied to the clipboard can be added with the menu item Edit → Paste.

Since the file name in the image file must conform to the 8.3 format, you will be asked for a suitable name for files that do not conform to this convention. If the order of the files in the image file matters, you can change it with the arrow keys in the toolbar.

In the second subwindow, you specify the format. Both the physical format (number of sides, number of tracks, sectors per track, and sector size) and the logical format (block size, block number format, and directory size) must be specified. For the most common CP/M variants of some emulated computer types, there is a dedicated selection button each, so that you do not need to specify the format in detail for those.

If the selected format contains one or more system tracks, you can specify a file in the lower area that is then copied to the system tracks.

After you have added all the desired files and selected the format, you still need to generate the actual image file. You do this with the menu item Save Disk Image File.... You will be asked for the file name. JKCEMU determines the file format from the file name's extension. Therefore, choose a file name with an extension customary for disk image files.

2.1. Interleave

In the Format subwindow, several floppy disk formats are shown, for which an interleave is specified, or which differ only in the interleave. Interleave serves to reduce access time when sequentially reading from and writing to real floppy disks and has no effect whatsoever in the emulator. The only reason an interleave is specified here at all, and thus made selectable, is to be able to create disk images with the same physical sector arrangement as the respective original formatting programs produce. If you select a format without an interleave, or the wrong interleave, that is not a problem. A real floppy disk written with such an image file would, in certain cases, only have somewhat longer access times.

2.2. DateStamper

If you have selected a floppy disk format with DateStamper support for the disk image file to be created, the file !!!TIME&.DAT is automatically created, which contains the timestamps of the individual files.

3. Creating an Image File from the Emulated System

With this variant, you create a new, i.e. empty, disk image file in the JKCEMU Floppy Disk Station window and format it from the emulated system with a suitable program. During formatting, the image file receives its content.

Formatting Emulated Floppy Disks

JKCEMU is able to format emulated floppy disks. However, there are a few things to keep in mind:
  1. The emulated floppy disk must be writable.
  2. If the emulated floppy disk already has a format (which is always the case, e.g., when using real floppy disks), the existing format cannot be changed. In that case, formatting is possible as long as only sectors are written that already exist on the emulated floppy disk.
  3. To write an image file with any format you like, you must create a new, i.e. empty, disk image file. You will find the corresponding menu items in the menu of the Load/Open button in the JKCEMU Floppy Disk Station window. Then start the appropriate formatting program in the emulator.
  4. If track 2 is formatted after track 0, JKCEMU assumes that a 40-track floppy disk is being formatted in an 80-track drive. JKCEMU then converts the track number accordingly, i.e. track 2 as set in the drive results in track 1 on the floppy disk (see The 40/80-Track Problem).

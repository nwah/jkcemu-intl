C-80

The C-80 is a single-board computer for home construction, presented by Joachim Czepa in 1986.

1. Emulated Hardware

  • 1 KByte ROM in the address range 0000h-03FFh
  • 1 KByte RAM in the address range 0C00h-0FFFh
  • 8-digit 7-segment display
  • hexadecimal keyboard with additional function keys
  • cassette recorder connection
Due to incomplete address decoding, the RAM is also visible in the range 0800h-0BFFh.

1.1. Keyboard

The table shows how the keys of the C-80 are mapped to the keyboard of the emulator's computer:
C-80 Key Key in the Emulator Meaning
RES Escape Reset
BRK N Abort (NMI)
FCN F1 Function key,
pressing it, releasing it again, and then pressing one of the keys 1 to 6 invokes a function for which there is no separate key.
MEM M Memory display
GO G Start program
REG R Display registers
- - Decrement value/address
+ + or Enter Increment value/address, or accept it
0...9 0...9 Address/data entry
A...F A...F or a...f Address/data entry

Caution! For the sake of simplicity, Escape and N trigger RESET or NMI without a confirmation prompt, even if the confirmation prompt is enabled for this in the settings.

2. Software Contained in ROM

  • Original monitor program

2.1. Notes on Using the Monitor Program

After a RESET, only a decimal point is visible.

2.1.1. Displaying/Changing Memory Cells

  1. Reset (key RESET (Escape))
  2. Call up the memory display (key MEM (M))
  3. Enter the address (keys 0...9 and A...F)
  4. Accept the address (key +)
  5. Change the address if necessary (keys + and -)
  6. Enter a value if necessary and accept it with the key +
  7. Continue with point 5


2.1.2. Starting a Program

RESET (Escape) → GO (G) → <start address> [ → - → <breakpoint address> ] → +

Pressing the minus key with entry of the breakpoint address can also be omitted.

Caution! A breakpoint can only be set in RAM and only on the first byte of an instruction.

The BRK (N) key (NMI) has the same effect as reaching the breakpoint.

2.1.3. Displaying/Changing Registers

RESET (Escape) → REG (R)

A double register is displayed. Use the keys + and - to switch to the next or previous double register.

The registers are changed by entering a byte and then assigning it, with +, to the higher-order register, or with - to the lower-order register, of the displayed double register.

2.1.4. Filling a Data Area

RESET (Escape) → FCN (F1) → 0 → <start address> → - → <end address> → + <value> → +

If the start address is smaller than the end address, an E is output as an error message.

2.1.5. Saving a Data Area to Tape

RESET (Escape) → FCN (F1) → 1 → <start address> → - → <end address> → +

If the start address is smaller than the end address, an E is output as an error message.

The recording format is compatible with the Poly-Computer 880. As a deviation from that, the last block is padded to 32 bytes. In addition, the C-80 also writes an end block with the block identifier FFFFh. Both the padding bytes and the end block are not evaluated when reading into the Poly-Computer.

Caution! Do not forget to enable the appropriate audio function in the emulator.

2.1.6. Loading a Data Area from Tape

There are two functions for loading from tape:
  1. RESET (Escape) → FCN (F1) → 2 → <start address> → - → <end address> → +
  2. RESET (Escape) → FCN (F1) → 3 → <start address> → - → <end address> → +

In the first case, reading is aborted when the entered end address is reached or a block with the end identifier is read.

In the second case, on the other hand, reading is only aborted when the entered end address is reached. If the file on the tape is smaller than the specified data area, the C-80 gets stuck while reading.

If the entered start address is smaller than the end address, an E is output as an error message.

Caution! Do not forget to enable the appropriate audio function in the emulator.

2.1.7. Transferring a Data Area

RESET (Escape) → FCN (F1) → 4 → <start address> → - → <end address> → + → <destination address> → +

If the start address is smaller than the end address, an E is output as an error message.

2.1.8. Port Input

RESET (Escape) → FCN (F1) → 5 → <port address> → +

The port address must be entered as a 16-bit value. Each time the + key is pressed, the input port is read and the value is displayed. Any other key aborts the function.

2.1.9. Port Output

RESET (Escape) → FCN (F1) → 6 → <port address> → + → <value> → +

The port address must be entered as a 16-bit value. Each time the + key is pressed, the entered value is written to the output port.

LC-80

The LC-80, also written LC 80 or LC80, is a single-board computer designed as a learning computer with a hexadecimal keyboard and a 7-segment display. It was produced from 1984 onward at VEB Mikroelektronik Erfurt with two different ROM fittings (2x U505 or 1x U2716).

A planned export order later led to the development of the LC80e, an enhanced version with double the clock frequency, more memory, and a chess program included in ROM. Since the export order never materialized, only development samples of the LC-80e ever existed.

There were also private further developments of the LC-80. One comes from Eckart Buschendorf and is called LC-80.2. Another was created between 2014 and 2016 in the retrocomputing scene and is called LC-80ex. All of these variants are emulated by JKCEMU.

1. Emulated Hardware

All model variants emulate:
  • 6-digit 7-segment display
  • HALT LED
  • OUT LED (sound output)
  • keyboard with hexadecimal and function keys
  • cassette recorder connector

1.1. LC-80 with ROM 2 x U505

  • 900 kHz clock frequency
  • 2 KByte ROM in the address range 0000h-03FFh and 0800h-0BFFh
  • 1 KByte RAM in the address range 2000h-23FFh

Caution! Due to incomplete address decoding, the address range 0000h-3FFFh is also visible in the ranges starting at 4000h, 8000h, and C000h.

1.2. LC-80 with ROM 2716

  • 900 kHz clock frequency
  • 2 KByte ROM in the address range 0000h-07FFh
  • 4 KByte RAM in the address range 2000h-3FFFh

The manufacturer shipped this LC-80 version with only 1 KByte of RAM. However, so that JKCEMU also offers a configuration that combines the original monitor program with the maximum RAM expansion, 4 KByte of RAM is emulated.

Caution! Due to incomplete address decoding, the address range 0000h-3FFFh is also visible in the ranges starting at 4000h, 8000h, and C000h.

1.3. LC-80.2

  • 900 kHz clock frequency
  • 4 KByte ROM in the address range 0000h-0FFFh
  • 4 KByte RAM in the address range 2000h-3FFFh

Caution! Due to incomplete address decoding, the address range 0000h-3FFFh is also visible in the ranges starting at 4000h, 8000h, and C000h.

1.4. LC-80e (Export Variant)

  • 1.8 MHz clock frequency
  • 12 KByte ROM in the address ranges 0000h-1FFFh and C000h-CFFFh
  • 4 KByte RAM in the address range 2000-3FFF

Caution! Because of the doubled clock frequency, the original LC-80 programs also run twice as fast. This is particularly important for time-critical programs (e.g. the clock program).

Note: By connecting a suitably large external ROM file, the ROM starting at address C000h can be enlarged to up to 16 KByte, so that up to 24 KByte of ROM in total are emulated.

1.5. LC-80ex

  • 1.843 MHz clock frequency
  • 20 KByte ROM in the address ranges 0000h-1FFFh, A000h-BFFFh, and C000h-CFFFh,
  • 32 KByte RAM in the address range 2000-9FFF including Timekeeper RAM
  • 2 serial interfaces (Z80 SIO at I/O ports DCh-DFh, see also LC-80ex SIO Speed)
    • Channel A: printer
    • Channel B: TV Terminal 1.2 (alphanumeric)
  • USB connector (Vinculum VDIP module at I/O ports BCh-BFh)
  • real-time clock (read-only) Timekeeper MT48T08 with working cells in the address range 7FF9h-7FFFh

Caution! Because the clock frequency is more than double that of an original LC-80, programs run correspondingly faster.

Note: By connecting a suitably large external ROM file, the ROM starting at address C000h can be enlarged to up to 16 KByte, so that up to 32 KByte of ROM in total can be emulated.

1.7. Sound Output

The LC-80 has only one sound output, which is used both for acoustic purposes and for saving programs to tape. You enable this sound output in the Audio/Tape window on the Tape Output tab.

2. Software Contained in ROM

  • LC-80 with 2 KByte ROM:
    • original monitor program
  • LC-80.2:
    • extended and improved monitor program by Eckhard Buschendorf
  • LC-80e:
    • original monitor program for the LC-80e
      (adapted to the clock frequency)
    • chess program SC-80
  • LC-80ex:
    • original monitor program for the LC-80e
    • LCTools 4 by Rolf Weidlich
    • LC80ex-BASIC 2.0*USB by Rolf Weidlich
      (an adaptation of the AC1/LLC2 Graphics/Sound BASIC to the LC-80ex)
The original monitor programs of the individual LC-80 versions are functionally identical, but differ in their binary image, especially in the case of the LC-80e/LC-80ex.

Caution! On the LC-80 with the U505 fitting, part of the monitor program, and thus also of the system functions, is located at other addresses. Programs that use these system functions therefore either do not run at all, or only run on this LC-80 version.

2.1. Notes on Operating the Original Monitor Program

After being switched on, the LC-80 plays a tune. For you to hear this in the emulator, you must enable sound output in the Audio/Tape window on the Tape Output tab and then invoke the menu item Power On in the Extras menu.

2.1.1. Display

For address input and output, the display is usually split in two: The first four digits show the address, and the last two digits show the data byte that was read from that address.

To the left of the display, the two LEDs are emulated:
Green LED:output
Red LED:HALT state


2.1.2. Loading a Program from Tape

RES (Escape) → LD (L) → <file name> → EX (Enter)

The file name is a four-digit hexadecimal number.

If you do not know the file name, simply enter any number. In that case, i.e. if the file name is wrong, the file is not loaded, but the LC-80 briefly displays the file name stored on tape as soon as the corresponding tape position is read.

After reading, the display shows the end address + 1, or, in case of an error, the message Error.

Caution! In JKCEMU you must enable the input-side emulation of the cassette recorder connector.

2.1.3. Saving a Program to Tape

RES (Escape) → ST (S) → <file name> → + → <start address> → + → <end address + 1> → EX (Enter)

The file name and the addresses are each a four-digit hexadecimal number.

Caution! In JKCEMU you must enable the output-side emulation of the cassette recorder connector.

2.1.4. Starting a Program

RES (Escape) → ADR (F1) → <start address> → EX (Enter)

The address is a four-digit hexadecimal number.

Most game and application programs are started at address 2000 (start of RAM).

2.2. Chess Program SC-80

The chess program SC-80 is only included in the LC-80e and is started at address C800. To do so, enter:

RES (Escape) → ADR (F1) → C → 8 → 0 → 0 → EX (Enter)

When the message SC-80 appears, the chess program has started.

The chess program uses the non-maskable interrupt to restart, i.e. pressing the N key restarts the chess program, but only after the chess program has been started once in the manner described above.

2.2.1. Keyboard

The keys have a different meaning or assignment in the chess program than in normal LC-80 mode. With the original, there was a template that was placed over the keyboard and that contained the changed labeling of the keys for the chess program. The digit keys are the same in LC-80 and SC-80 mode. However, the letter and special keys differ. So that both modes can be operated conveniently in the emulator, JKCEMU automatically detects whether the chess program is running and switches the key mapping between LC-80 and SC-80 mode accordingly. If you have opened the window with the keyboard view of the LC-80, its key labels change accordingly as well, i.e. JKCEMU applies the SC-80 template on its own.

The automatic chess mode detection works according to the following principle: When program execution reaches address C800 (the start address of the chess program), the key mapping is switched to SC-80 mode. From then on, JKCEMU assumes that returning to the monitor program is only possible via RESET, i.e. when address 0000 is reached, it switches back to LC-80 mode.

2.2.2. Playing Against the Computer

After starting the chess program, press NEW GAME / LEV (F1) to enter play mode. By pressing this key again and then entering a number from 0 to 6, you can select the playing strength. The playing strength is set to 1 by default. You can also change the playing strength later during the game, whenever it is your turn.

If you want to play White, now enter your first move, e.g. E2E4, and confirm with EX (Enter). The computer now thinks and displays its move. Now it is your turn again, and so on.

Caution! When the computer displays its move, you must wait about 15 seconds before you can enter a move yourself again. In the chessboard window, the move is also only shown after this waiting period.

If you want the computer to play White, then after pressing NEW GAME / LEV (F1), or after selecting the playing strength, press the key COLOR (W). WHITE appears in the display. Now press the key SELF PLAY / SW (F2). The computer then displays its first move. Now it is your turn.

2.2.3. Corrections

If you made a typing mistake while entering a move and have not yet confirmed with EX (Enter), simply keep typing additional characters until the message SC-80 appears. Now enter the correct move and confirm.

If your entry is invalid, the message Error appears. Simply enter a valid move and confirm.

Your move is also not accepted if it is valid, but would leave your king in check.

2.2.4. Random Number Generator

The chess program also contains a random number generator, so that it does not always play the same moves. You can influence this random number generator by pressing RANDOM (R) and then entering a digit from 0 to 9.

2.2.5. Signaling of Game Situations

If the computer puts you in check, an S appears in the first digit of the display. On checkmate, you see an M.

2.2.6. Letting the Computer Play Against Itself

You can also let the computer play against itself by entering the following after starting the chess program:

NEW GAME (F1) → SELF PLAY (F2)

2.3. LCTools

LCTools is only included in the LC-80ex and resides in the address range A000h-BFFFh. It provides the following functions:
  • loading and saving programs via the serial interface (not usable in the emulator)
  • loading and saving programs via USB in Headersave format

These functions can be used both interactively via the hexadecimal keyboard and via a jump table from within programs. In addition, three programs are included:
  • Timekeeper clock (start at address A030h)
  • A/D converter (start at address A033h)
    Caution! Since no corresponding hardware is emulated, this program cannot be used in JKCEMU.
  • machine code editor (start at address B000h)

2.4. BASIC

The BASIC interpreter is only available in the LC-80ex and resides in the address range C000h-DFFFh. It requires LCTools in the address range A000h-BFFFh, as well as a terminal connected to SIO channel B. JKCEMU emulates the TV Terminal 1.2 as a second display unit, i.e. you operate the BASIC interpreter through the terminal window, which is opened via the menu item Extras → Second Display Unit....

BASIC is started at address C000h. To do so, enter the following in the JKCEMU main window:

RES (Escape) → ADR (F1) → C → 0 → 0 → 0 → EX (Enter)

Only then do you switch to the terminal window. If you exit the BASIC interpreter with BYE and want to restart it without losing data, use address C003h (the warm start address).

This BASIC is an adaptation of the AC1/LLC2 Graphics/Sound BASIC and thus offers a similar range of functions to it. However, direct access to the keyboard and pseudo-pixel graphics (SET, RESET, POINT) are not possible. In return, BASIC programs are saved to a USB storage device (commands SAVE, LOAD, and FILES). Printing is possible with LFILES, LLIST, and LPRINT, and editing a BASIC program with the command EDIT. Finally, the functions DATE$(0) and TIME$(0) should be mentioned, which let you read the real-time clock.

3. Miscellaneous

3.1. AutoLoad and AutoInput

On the LC-80, RESET causes a warm start, during which no data is lost. For this reason, it is quite common to trigger a RESET before executing a command. Since AutoLoad and AutoInput would interfere in such cases, AutoLoad and AutoInput are only executed on a cold start (emulated power-on).

Caution! Since, in the LC-80 emulation, the Escape key triggers a RESET (warm start), an Escape in AutoInput likewise causes a RESET.

Caution! AutoInput only performs automatic keystrokes on the hexadecimal keyboard. The alphanumeric keyboard emulated on the TV Terminal cannot be operated this way.

3.2. LC-80ex SIO Speed

On the LC-80ex, the SIO channels are by default clocked by CTC channel 0. This allows standardized speeds of up to 2400 baud to be achieved. Since this is rather slow, however, Rolf Weidlich created a circuit extension in which the SIO channels are fed directly from the CPU clock via a 1:12 divider. This yields a speed of 9600 baud without any change to the software. JKCEMU emulates this circuit extension and thus the 9600 baud rate.

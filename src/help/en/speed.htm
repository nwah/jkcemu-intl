Emulation Speed

By default, the emulation is throttled so that it corresponds to the original speed of the emulated computer. In the Settings, however, you can also specify any clock frequency you like, and thus emulate a different speed.

Should the processing power of the emulator computer, i.e. the computer on which JKCEMU runs, not be sufficient to reach the original or the desired speed, the emulation is not throttled. You can see the speed reached (emulated clock frequency) in the status bar.

Emulation at Maximum Speed

In some cases you may want the emulation to run at the highest possible speed. This is possible with a click on the menu item Maximum Speed in the Extra menu of the main window. Clicking this menu item again, which is now called Standard Speed, switches the speed back.

Caution! If sounds are output via the sound system or data is read (see Audio/Tape), the Maximum Speed function has no effect, since the emulator is then forcibly throttled to the configured speed. This also applies if you read or write a sound or tape file and have Monitor enabled while doing so.

Things are somewhat different if the emulated system has a separate sound generator that produces sound. In that case, the emulation of the microprocessor system is not forcibly throttled.

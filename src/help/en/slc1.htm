SLC1 Chess and Learning Computer

The SLC1 chess and learning computer was presented by Dr. Dieter Scheuschner in Schaltungssammlung für den Amateur, 5th installment 1989. It is a home-built computer.

The SLC1 was primarily designed as a chess computer. However, it also has a small monitor program for learning and demonstration purposes.

1. Emulated Hardware

  • 4 KByte ROM in the address range 0000-0FFF
  • 1 KByte RAM in the address range 5000-53FF
  • 6-digit 7-segment display
  • Busy LED
  • Keyboard with 12 keys
The choice between ROM and RAM is made using address line A14. Because of this incomplete address decoding, the memory is visible throughout the entire address space.

1.1. Keyboard

The SLC1 has a chess program and a monitor program. The key assignment is completely different between the two programs. For this reason, the emulator detects when the chess or the monitor program is started and switches the key mapping accordingly. This allows both the chess program and the monitor program to be operated with the intuitively correct keys on the emulator computer's keyboard.

1.1.3. Keyboard Display in a Window

The menu item Extra → Keyboard... opens a window that shows the keyboard schematically. Since, in the original, the labeling of the keys differs between the chess and the monitor program, for simplicity the window only shows the labeling of the program you are currently in. Switching between the two views happens automatically. After RESET you therefore see the key labeling of the chess program. If you now press the key A 1 five times to switch from the chess program to the monitor program, the keyboard view switches accordingly as well.

2. Software Contained in the ROM

  • Chess program
  • Monitor program

After starting, or after a RESET, you are in the chess program.

2.1. Notes on Operating the Chess Program

When the chess program starts, the computer sets up the starting position, i.e. you play with the white pieces. If you want to play black, first press the key Z (Enter).

Now you can set the playing strength (1 to 8):

A (F1) → <playing strength> → St (F2)

You can return to the starting position at any time with the key C (Escape).

2.1.1. Switching Sound On and Off

A (F) → Z (Enter) → St (F2)

Caution! In the emulator, you only hear the sound if you enable the sound output in the Audio/Tape window, on the Loudspeaker tab.

2.1.2. Entering and Correcting Moves

To enter a move, simply type the starting and destination square one after the other and finish with Z (Enter). As long as you have not yet completed the entry, you can use St (F2) to clear the incorrect entry and enter your move again.

If the entered move is invalid, the display blinks to prompt you to enter a new move.

2.1.3. Castling

For castling, you enter the corresponding king move.

2.1.4. Displaying the Board Position

JKCEMU shows you the board position in a separate window, but for the sake of completeness the corresponding function of the chess program is also explained here. In addition, this function is needed when entering a chess problem.

You reach the board display by pressing the key A (F1) three times. The display shows A1, followed by a code. The code indicates the occupancy of square A1 and has the following meaning:
CodeMeaning
01white pawn
02white knight
03white bishop
04white rook
05white queen
06white king
FAblack king
FBblack queen
FCblack rook
FDblack bishop
FEblack knight
FFblack pawn
--square not occupied

Each further press of the key A (F2) shows the next square. You return to game mode with St (F1).

2.1.5. Entering a Chess Problem

To enter a chess problem, you must change the board position accordingly. Press A (F1) repeatedly until you reach the board display. Keep pressing A (F1) until the first, or the next, square to be changed is shown. Now enter the code (1 to 6) for the desired piece. For a black piece you must enter the code of the corresponding white piece twice. If you want to remove the piece from the displayed square, enter 7 or 8 as the code.

2.2. Notes on Operating the Monitor Program

You start the monitor program from within the chess program by pressing A1 (A or 1) five times.

2.2.1. Entering an Address and Data

You begin entering an address with the key ADR (F1). Then you enter the four-digit address. For the hexadecimal digits 8 through F you must first press the key Seq (S) to enter shift mode.

After you have entered four hexadecimal digits, the two leftmost positions show the data byte at that address. If you now enter further hexadecimal digits, you switch to data entry, i.e. you change the data byte shown at the far left. However, it is not written to memory until you press +/- (+). At the same time, the next address is displayed. If you want to switch to the previous address instead of the next one, press the key Seq (A) before pressing + / -.

2.2.2. Starting an Application Program

First enter the start address, then call up the GO function, i.e. the complete entry sequence looks like this:

ADR (F1) → <address> → Fu (F2) → GO (H)

The application program can jump back into the monitor program by jumping to address 05F4. The memory cell whose address is in register DE is then displayed.

2.2.3. Further Functions

The monitor program offers further functions, which, however, are also available directly in JKCEMU in a more convenient form (see Debugger and Memory Editor). If you nevertheless want to explore these further functions of the monitor program, please refer to the corresponding literature.

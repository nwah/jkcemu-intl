Printing Help Pages

You can print the individual help pages. To do so, call up the Print... function. With Print Options... you specify whether the page number should appear.

Each help page is printed exactly as it appears in the help window. For example, if you widen the help window, the help pages will also appear wider in the printout. However, to prevent printing beyond the page margin, the printout is scaled down as needed. This lets you determine the appearance and, indirectly, also the font size of the printed pages yourself.

Memory Address Notation

Addresses in the memory of the emulator or of an emulated system are always given as hexadecimal numbers.

VCS80

The VCS80, also written VCS 80 or VCS-80, is a home-built learning computer whose construction plans were published by Eckhard Schiller in 1983 in the magazine radio fernsehen elektronik.

1. Emulated Hardware

  • 0.5 KByte ROM in address range 0000-01FF
  • 1 KByte RAM in address range 0400-07FF
  • 8-digit 7-segment display
  • Hexadecimal keyboard with additional function keys
Due to incomplete address decoding, the ROM is also visible in the range 0200-03FF.

The 7-segment display actually has 9 digits. However, the middle digit is not used. This leaves four digits on the left and four digits on the right.

1.1. Keyboard

The table shows how the keys of the VCS80 are mapped to the keyboard of the computer running the emulator:
VCS80 Key Key in the Emulator Meaning
RESET Escape Reset
PE P Peripheral input,
not assigned an independent function by the monitor program
ST S Single-step mode
TR T Enter breakpoint
GO G Start program
RE R Display registers
MA M Accept entered address
A- - Previous address
A+ + Next address
0...9 0...9 Address/data entry
A...F A...F or a...f Address/data entry

Caution! For the sake of simplicity, Escape triggers RESET without a safety prompt, even if the safety prompt is enabled for this in the settings.

2.1. Notes on Operating the Monitor Program

After a RESET, Mo is shown on the left and any address on the right.

2.1.1. Displaying/Changing Memory Cells

  1. Reset (key RESET (Escape))
  2. Enter address (keys 0...9, A...F, A+ (+) and A- (-))
  3. Accept address (key MA (M)),
    You are now in the main cycle, i.e. digits 7 and 8 show the byte at the accepted address and the two digits before that show the byte of the previous address.
  4. If necessary, enter a value (keys 0...9 and A...F)
  5. Accept the value and display the next address (key A+ (+)),
  6. Continue with point 4


2.1.2. Displaying/Changing Registers

RESET (Escape) → RE (R)

The AF register is displayed. With the keys A+ (+), A- (-), MA (M), RE (R), and GO (G) you switch to the registers BC, DE, HL, IX, and IY respectively. Any other function key leads to the main cycle.

2.1.3. Starting a Program

RESET (Escape) → GO (G) → <address> → <any function key>

2.1.4. Single-Step Mode

RESET (Escape) → <address> → MA (M) → ST (S)

Each time you press the key ST (S), one instruction is now executed. Before the instruction to be executed, an interrupt-enable instruction is written and this is also jumped to. During instruction execution, address line A0 then triggers an interrupt via PIO bit B7. The interrupt service routine corrects the memory cell into which the interrupt-enable instruction was written and returns to the input loop.

The following restrictions apply to single-step mode:
  • The memory cell before the instruction to be executed must be RAM.
  • No instructions that affect the interrupt system can be executed in single-step mode.

2.1.5. Breakpoint

RESET (Escape) → TR (T) → <address> → <any function key>

A restart instruction is written to the specified address. When program execution reaches this instruction, the memory cell is written back with its original value and execution returns to the input loop.

A breakpoint can only be set on a RAM address.

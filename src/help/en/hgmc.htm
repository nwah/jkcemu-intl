Hübler-Grafik-MC

In 1988, Bernd Hübler published the construction plans of a home-built computer in the book Mikroelektronik in der Amateurpraxis 3 under the title BASIC-Kleincomputer mit Grafik. Since this computer has no name of its own and the title of the publication is not suitable as one either, the computer is called the Hübler-Grafik-MC in JKCEMU.

1. Emulated Hardware

  • 4 or 18 KByte ROM, depending on the setting
  • 64 KByte RAM including video RAM
  • CTC
  • PIO
  • optional:
    • KCNet-compatible network card at I/O base address C0h
    • USB port (Vinculum VDIP module) at I/O base address FCh
Of the I/O system, only the CTC and the PIO are emulated. The SIO and the cassette recorder interface, as well as any hardware connected to the PIO, are not emulated.

1.1. Memory Configuration

The memory configuration can be changed using output instructions:
Output AddressMeaning
00h-03h Switch off ROM and switch on the full 64 KByte of RAM
04h-07h Switch on ROM and switch off the lower 32 KByte of RAM
10h-13h Set the start address of the video RAM,
bits 5 to 7 of the output value set bits 13 to 15 of the start address.

1.2. Printer

A printer is emulated by JKCEMU intercepting the operating system calls for print output and appending the data to the current print job. This function can be switched off in the Settings.

2. Software Contained in ROM

  • Monitor program version 3.0
  • Slightly modified HBASIC 3.3 (optional, see section 3.1.)
In the monitor program, you can display a list of all commands with HELP. The list contains both the commands of the monitor program itself and those that may be found elsewhere in memory.

3. BASIC

3.1. BASIC Interpreter

The Hübler-Grafik-MC was designed as a BASIC computer. However, the corresponding BASIC interpreter is not contained in ROM in the original. It has to be loaded from cassette.

So that you do not always have to load this interpreter first in the emulator, JKCEMU offers the option BASIC interpreter contained in ROM in the Settings. If this option is switched on, the now enlarged ROM contains the monitor program, the BASIC interpreter, and a loader routine to be started with the command BASIC, which copies the interpreter from ROM to RAM and starts it there (cold start).

However, the original BASIC interpreter also provides a command named BASIC. So that no confusion arises, this command was renamed to WBASIC in the BASIC version contained in JKCEMU. This means that BASIC performs a cold start and WBASIC a warm start of the interpreter.

The return from the BASIC interpreter to the monitor program is done using RESET.

3.2. Saving and Loading BASIC Programs

JKCEMU offers special support for saving and loading BASIC programs. To save, please use the function Save BASIC program... in the File menu and save the respective program as a BASIC/RBASIC program file (*.bas). Alternatively, you can also save it as a Headersave file (*.z80) with file type B.

If you save a BASIC program in a different file format, JKCEMU will no longer recognize, when later loading the file, that it is a BASIC program, and will not adjust the system cells of the BASIC interpreter accordingly. The loaded program cannot then be used.

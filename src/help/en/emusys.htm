German Umlauts

Some emulated systems support German umlauts, others do not. When a character set contains German umlauts, they are frequently mapped onto some ASCII characters (that was common practice back then, see also the German variant of ISO646). The German umlauts thus have the same codes as some ASCII characters. For this reason, on these systems JKCEMU also maps the umlauts onto the codes of the corresponding ASCII characters. If you enter an ä, for example, the emulator generates code 5Bh, which also stands for the ASCII character [. If the character set contains German umlauts, you will then see the ä, otherwise the opening square bracket.

Conversely, i.e. when you save the screen output of the emulated system to a text file or copy it as text to the clipboard, JKCEMU converts the umlauts back into the codes of the system character set, but only if the character set also contains umlauts.

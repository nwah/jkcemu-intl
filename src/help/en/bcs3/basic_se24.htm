BASIC-SE 2.4

BASIC-SE 2.4 is a simple BASIC dialect with 16-bit integer arithmetic.

1. Commands

LIST Display the program
NEW Delete the program
RUN Start the program


2. Line Format, Entering a Program Line

A program line begins with the line number (1 to 9998), followed by one or more statements, which must be separated by a semicolon. The line 9999 END is appended automatically.

3. Number Format

The numbers (always integers) are represented internally with 1 sign bit and a 15-bit magnitude, i.e. not in two's complement.

4. Constants

Decimal numbers: -32627 to 32627
Hexadecimal numbers: 0 to 0FFFH


5. Variables

Variable names consist of one or two letters. The names IF, OR, and any name beginning with the letter H, are forbidden.

6. Operators

* Multiplication
/ Division, always rounds down
- Subtraction
+ Addition
OR Bitwise inclusive OR
AND Bitwise AND
> Greater than,
Result is 0 or 1.
< Less than,
Result is 0 or 1.

Operators listed higher up have precedence, i.e. if all 8 operators occur in a numerical expression, the multiplication is performed first and the comparison greater than last. Round brackets can be used to enforce a different execution order.

7. Statements

StatementMeaning
CLEAR Clear the screen
END End the program,
The line 9999 END is appended automatically.
GOSUB <line number> Calls a subroutine,
The line number can also be given as a variable numerical expression.
GOTO <line number> Jumps to a program line,
The line number can also be given as a variable numerical expression.
IF <numerical expression> THEN <statements> Conditional program execution,
If the expression has a value not equal to zero, the statements following THEN are executed.
INPUT [ <string literal> , ] [ <space expression> , ] Variable> [ , ... ] Reads numbers and writes the entered value into a variable,
The screen output is described under the PRINT statement.
LET <variable> = <numerical expression> Value assignment,
The keyword LET can be omitted.
OUT <port address> , <numerical expression> The value of the numerical expression is output on the specified I/O port.
POKE <address> , <numerical expression> The value of the numerical expression is written into the memory cell at the specified address.
PRINT [ <string literal> ] [ , ] [ <space expression> ] [ , ] [ [ BYTE ] <numerical expression> ] [ , ... ] Output on the screen:
  • String literal:
    A character string enclosed in single quote characters
  • Space expression:
    Syntax: # <numerical expression>
    As many spaces are output as the value of the numerical expression.
  • BYTE:
    If the keyword BYTE precedes a numerical expression, the low-order byte of the value is output in hexadecimal.
REM <comment> The text following REM is treated as a comment up to the next semicolon or the end of the line.
RETURN Ends a subroutine


8. Functions

FunctionMeaning
IN( <port address> ) Reads the specified I/O port
PEEK( <port address> ) Reads the specified memory cell
RND( <numerical expression> ) Determines a random number between 1 and the specified expression (max. 255)

BASIC-SE 3.1

BASIC-SE 3.1 is a BASIC dialect with 16-bit integer and 32-bit floating-point arithmetic as well as string processing.

1. Starting the System

After a cold start, you must first enter the number of visible lines. Only then do you reach the command mode.

2. Commands

LIST Display the program
LOAD Load from tape
NEW Delete the program
RUN Start the program
SAVE Save the program to tape
SAVED Save the program and the following RAM area to tape


3. Line Format, Entering a Program Line

A program line begins with the line number (1 to 9998), followed by one or more statements, which must be separated by a colon. The line 9999 END is appended automatically.

4. Data Types

There are integers (whole numbers with a magnitude less than 32628) and floating-point numbers as well as strings.

5. Constants

Integers:-32627 to 32627
Floating-point numbers: 0.0000001 to 9999999
Hexadecimal numbers: Start with a digit and end with an H,
e.g.: 0F000H
String literal: A string enclosed in single quote characters,
e.g. 'ABC'


6. Variables

Numeric variables can be named with a letter, two letters, or a letter and a digit. One- and two-dimensional arrays are also possible.

The names of string variables consist of a letter followed by the currency symbol.

Numeric arrays as well as string variables must be declared with the DIM statement.

7. Operators

* Multiplication
/ Division
- Subtraction
+ Addition
OR Bitwise inclusive OR
AND Bitwise AND
> Greater than
The result is 0 or 1.
< Less than,
The result is 0 or 1.
# Not equal,
The result is 0 or 1.
= Equal,
The result is 0 or 1.

Operators listed further up take precedence, i.e. if all 10 operators occur in a numeric expression, multiplication is performed first and the equality test last. However, this order of precedence does not correspond in every respect to the rules of mathematics! Furthermore, BASIC-SE 3.1 is not entirely free of errors at this point, either. For this reason, you should determine the order of execution yourself by using parentheses.

8. Statements

StatementMeaning
CLS Clear screen
DATA <expression> [ , ... ] Data area (list of numbers and/or strings)
DIM Declare and dimension array and string variables,
Example: DIM A(5), B2(6,7), C$(10)
END End the program,
The line 9999 END is appended automatically.
FOR <start value> TO <end value> [ STEP <step size> ] Beginning of a loop
GOSUB <line number> Call a subroutine,
The line number can also be given as a variable numeric expression.
GOTO <line number> Jump to a program line,
The line number can also be given as a variable numeric expression.
IF <numeric expression> THEN <statements> Conditional program execution,
If the expression has a value other than zero, the statements after THEN are executed.
INPUT [ <string literal> , ] variable> [ , ... ] Input of numbers and writing of the entered value to a variable
LET <variable> = <expression> [ , ... ] Value assignment,
The keyword LET can be omitted.
NEXT End of a FOR loop
OUT <port address> , <value> [ , <value> [ , ... ] ] Output the value or values to the specified I/O port
PLOT <x> , <y> Set a pixel using pseudo-graphics,
A character cell is divided into four pixels for this purpose.
POKE <address> , <value> [ , <value_2> [ , ... ] ] The value is written to the specified memory cell, value 2 to memory cell + 1, and so on.
PRINT [ <expression> ] [ , ... ] [;] Output to the screen,
Expression: numeric or string expression,
If a percent sign precedes an integer expression, the value is output in hexadecimal.
READ <variable> [ , <variable> [ , ... ] ] Read the next element or elements of the data area created with DATA into the specified variables,
The read pointer is advanced accordingly.
REM <comment> The text after REM is treated as a comment.
RESTORE Reset the read pointer for READ
RETURN End a subroutine
UNPLOT <x> , <y> Clear a pixel using pseudo-graphics,
A character cell is divided into four pixels for this purpose.


9. Functions

FunctionMeaning
CHR$( <numeric expression> ) Determine the ASCII character whose value equals the expression
IN( <port address> ) Read the specified I/O port
INKEY$ Query the keyboard,
If a key is pressed, the character is returned.
INT( <numeric expression> ) Determine the next smaller whole number,
If the magnitude of the value is less than 32628, the floating-point number is internally converted to an integer.
LEN( <string expression> ) Determine the length of a string
PEEK( <port address> ) Read the specified memory cell
RND Determine a random number between 0 and 0.9999
USR( <address> ) Call a machine code subroutine
The return value is the content of registers CBLH.


10. Error Messages

@ Neither a number nor a keyword
A Arithmetic error
B Syntax error
D DATA missing
F Function and statement confused
I Not an integer
M Memory full
U Overflow in PLOT/UNPLOT or arrays
$ (currency symbol) Not a string
= () This character is missing

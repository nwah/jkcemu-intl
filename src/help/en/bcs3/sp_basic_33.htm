S/P-BASIC V3.3

S/P-BASIC V3.3 is a further development of BASIC-SE 3.1 created by Frank Prüfer, which, besides extensions to the language scope, also offers improved system stability. Only the essential differences are described below.

1. Operator Execution Order

The execution order was changed, but, as with BASIC-SE 3.1, still does not correspond to the mathematical rules. It is therefore advisable to fix the execution order yourself by using round brackets.

2. New and Changed Statements

StatementMeaning
CALL <address> [ , ... ] Call a machine code subroutine without returning a value
IF <condition> THEN ... Conditional program execution,
The syntax of the IF statement has not changed. However, there are differences in the logic when more than one statement follows the keyword THEN: If the condition is not met, execution continues with the next program line rather than, as with BASIC-SE 3.1, with the statement after next following THEN.
PRINT [... [, ...]] [;] PRINT has gained a construct for outputting spaces:
& <expression>
As many spaces are output as the value of the expression.
RANDOMIZE Sets a random starting value for the random number generator (RND function)


3. New and Changed Functions

FunctionMeaning
ASC( <string expression> ) Determines the ASCII code of the first character of the passed string
USR( <address> )
USR( <address> , <value> ) 		Calls a machine code subroutine that returns a value in the registers BC and HL,
It is also possible to pass a value in these registers.


4. New and Changed Error Messages

U Undefined character, neither a number nor a keyword
S Syntax error
O Overflow during PLOT/UNPLOT or with arrays
L Line not found
T Reading from magnetic tape failed,
You should reinitialize everything with NEW.

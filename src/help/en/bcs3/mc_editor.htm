Machine Code Editor

Torsten Musiol developed a machine code editor for the BCS3, which is also integrated into the emulator. Since this machine code editor only runs correctly with BASIC-SE 3.1 for 29 characters per line, it is only available as a ROM in main memory for that BASIC version.

The machine code editor requires at least 20 visible lines. Please set an appropriate number of lines when performing a cold start of BASIC-SE 3.1.

Invocation

Enter the following line in BASIC-SE 3.1:

Y=USR(0F000H)

The machine code editor responds with: EDIT>
You are now in the command loop.

Commands

CommandMeaning
G<address> Go
Start a machine code subroutine at the specified address.
A RETURN instruction jumps back to the command loop.
M<addr1>-<addr2>-<addr3> Move
Copy the memory area from <addr1> to <addr2> to <addr3>,
The memory areas may overlap.
S<address> Substitute
Write memory cells starting at the specified address,
Use the keys O, L, I and P to move the cursor to the desired memory cell. Then enter the byte to be written in hexadecimal and press the ENTER key. The Q key returns to the command loop.
T<address> Test
Like command G, except that when returning from the machine code subroutine, the registers AF, BC, DE and HL are output.
Q Quit
Return to BASIC-SE 3.1

Kramer-MC

In his book Praktische Mikrocomputertechnik, published in 1987, Manfred Kramer published the construction plans for a home-built computer. Since he did not give this computer any particular name, it is called the Kramer-MC here.

What is special about this computer is that, besides the hardware, a lot of attention was also paid to the software. For example, the Kramer-MC's ROM contains all the essential tools for software development in assembler and BASIC.

1. Emulated Hardware

  • 23 KByte ROM
  • 41 KByte RAM including 1 KByte video RAM
  • 64x16 character screen size


1.1. Printer

A printer is emulated by having JKCEMU intercept the operating system calls for print output and append the data to the current print job. However, this function is disabled by default and must be enabled in the Settings if needed.

The reason for this is that after a RESET, the logical printer channel points to the screen, and the monitor program also outputs its startup message via it. If interception of print output is enabled, a print job containing the short startup message is therefore created on every RESET. To avoid this inconvenience, the printer emulation is disabled by default.

2. Software Contained in the ROM

  • Monitor program
  • Assembler
  • Disassembler
  • Debugger
  • BASIC interpreter
  • Editor

4. Saving and Loading BASIC Programs

JKCEMU offers special support for saving and loading BASIC programs. To save, please use the function Save BASIC Program... in the File menu and save the respective program as a BASIC/RBASIC program file (*.bas). Alternatively, saving as a Headersave file (*.z80) with the file type B is also possible.

If you save a BASIC program in a different file format, JKCEMU will later no longer recognize, when loading the file, that it is a BASIC program, and will not adjust the system cells of the BASIC interpreter accordingly. The loaded program cannot then be used.

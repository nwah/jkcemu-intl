File Converter

The JKCEMU File Converter lets you convert memory image and disk image files, as well as sound files, into various formats. To do so, start the converter via the menu item Extra → Tools → File Converter. It is also possible to start the File Converter as a standalone program without the emulator. To do so, specify the option --fc or --fileconverter on the command line when starting JKCEMU. Optionally, a file can also be specified after it, which is then opened in the converter.

In the File Converter window that then appears, select the file to be converted under Source File. You can also drag the file from a File Browser into the window using drag&drop and release it over the file name field.

Once the file has been selected, the converter analyzes the file and shows, under Output File, the possible file formats into which the source file can be converted. Now select the desired output format and press Convert. A file selection dialog then asks you for the name of the output file, and the conversion is already complete. No completion message appears. The source file is retained.

For a sound file or a disk image file as the output file, you determine the specific format via the file extension. Which sound file formats are possible depends on the Java platform on which JKCEMU is running. Sound files can also be compressed with GZIP right away during conversion. To do so, the extension .gz must be appended to the name of the output file, after the extension of the sound file format (e.g. outputfile.wav.gz). Furthermore, you can play back the generated sound file directly, without it having to be saved. This makes it possible, for example, to transfer it via an audio cable to a real computer.

If, after selecting the source file, the list of possible output formats remains empty, there is no way to convert it, i.e. the format of the source file is not supported by the converter.

Caution! If, when converting a disk image file, you get an error message that a certain sector was not found, the source file contains an irregular sector arrangement, but the output file's format does not support that. In that case, you must change the output format. The following formats support a free sector arrangement: AnaDisk, CPC Disk, ImageDisk, and TeleDisk.

Caution! KCB files and certain Headersave files contain KC BASIC programs with possibly additional machine code and data areas. These files can be converted both into a format for system programs and into a format for KC BASIC programs. In the latter case, the output file contains only the actual BASIC program, i.e. any machine code or data areas are lost in the process.

Caution! For multi-KC-TAP files, i.e. TAP files that consist of several individual KC-TAP files and thus represent several consecutive tape recordings, only the first part is converted. The only exception is the output format Sound file in KC format, converted 1:1 from a KC-TAP or KC-Multi-TAP file. With this format, the contents of the TAP file are converted 1:1 into audio data. This also makes it possible to convert multi-KC-TAP files as well as KC-TAP files with an irregular structure. However, no header data can be changed for this format.

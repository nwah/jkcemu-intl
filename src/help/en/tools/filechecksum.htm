Checksum/Hash Value Calculation

In this window, which you reach via the File Browser, you can have checksums and hash values of files calculated. To do so, in the File Browser, select the desired files and call up the function Compute Checksum/Hash Value... in the File menu. In the window that then appears, select the desired algorithm and press the Calculate button.

Supported Algorithms

The following checksum calculations are supported:
  • Sum of bytes
  • Sum of 16-bit words (little endian)
  • Sum of 16-bit words (big endian)
  • CRC-CCITT (CRC-16 HDLC)
  • CRC-32
  • Adler-32

The algorithms supported for hash value calculation depend on the Java runtime environment being used and can therefore change. Usually, the following algorithms are supported:
  • MD2
  • MD5
  • SHA (SHA-1)
  • SHA-256
  • SHA-384
  • SHA-512

Comparing an Actual Value with a Target Value

The point of the calculation is usually to compare the calculated value (actual value) with a given value (target value). This is especially convenient if you copy the target value to the clipboard, then select the file in question in the table field, and then call up the menu item Compare Value with Clipboard in the Edit menu. This compares the actual and target values, without regard for upper/lower case. In addition, spaces and other non-hexadecimal characters are also ignored. This means the comparison works reliably even when, for example, the target value is grouped with spaces for better readability. So you do not need to specially prepare the target value before copying it to the clipboard.

Furthermore, you also have the option of copying the calculated value to the clipboard, with the hexadecimal characters A through F copied as upper- or lower-case letters, as you prefer.

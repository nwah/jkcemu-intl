Calculator

JKCEMU includes a built-in calculator that, in addition to the usual pocket calculator functions, also supports calculating with binary, octal and hexadecimal numbers, as well as converting between a Unicode character and its numeric value. Besides the four basic arithmetic operations, the calculator also supports a whole range of mathematical functions and operations that are particularly useful in the context of computers.

A special feature of the calculator is that you can enter decimal numbers with up to 1000 digits before and 1000 digits after the decimal point, and the four basic arithmetic operations are calculated with this precision as well. However, there is the following exception for division: if the result has an infinitely long fractional part, it is truncated to a reasonable number of digits for output. All calculations beyond the four basic arithmetic operations are performed with the precision usual for computers, of about 15 digits (64-bit number format).

The calculator can also be started as a standalone program without the emulator. To do so, specify the option --ca or --calculator on the command line when starting JKCEMU.

1. Sub-Windows

The JKCEMU calculator supports multiple sub-windows (also called tabs). An independent calculator operates in each sub-window. You can find the functions for opening and closing sub-windows in the File menu. This lets you have several calculators open at the same time and thus perform several calculations in parallel.

When you close the last sub-window, the calculator window is also closed.

2. Operation

Each sub-window has an area for input at the top and one for the result output at the bottom. In the upper area, in the Expression field, please enter any character or a numeric expression, e.g.:

  sqrt(1600)

The result is recalculated with every keystroke. It can happen that, while you are typing, there are moments when the text entered so far does not yet correspond to a valid expression, and an error message therefore appears in the result field. Do not let this bother you; simply keep typing until your input is complete and syntactically correct.

If the result is not recalculated after every keystroke, simply press the Enter key.

In addition to the numeric value in various number bases, the result field also shows the Unicode character that has the same code. However, this character is only displayed correctly if the character set for the corresponding Unicode range is also installed on your computer.

3. Number Base

Binary numbers are marked with a leading $, hexadecimal numbers with a leading 0x or a trailing H, and octal numbers with a trailing Q. A decimal point turns a number into a floating-point number. A comma as a decimal point is not permitted, however. All other numbers are interpreted as decimal integers.

Find Files

JKCEMU offers the option of searching a directory, including its subdirectories, for files matching certain criteria. The files found can be opened, copied, renamed, deleted, or otherwise used.

1. Search Criteria

The search criteria specify which files are to be found. If no entries are made for file size and contained text, matching directory names are also searched for.

The search criteria are combined with AND, i.e. only the files are found that match all the specified search criteria.

1.1. File Name

You can specify the file name in the form of a file name mask. In this mask, the characters * and ? are interpreted as wildcards. The asterisk stands for any number of characters, and the question mark for exactly one arbitrary character. All other characters must match for the file in question to be found.

You can also specify several file name masks in the input field, by simply writing them one after another, separated by spaces, commas, or semicolons. The search criterion File Name is satisfied if one of these file name masks matches.

If a file name mask needs to contain a space, comma, or semicolon, you must enclose it in double quotes, so that these characters are not treated as separators. For example, use "* *" to search for all files that contain a space in their name. By contrast, * * without double quotes means the mask for all file names, written twice in a row.

The file name mask is a mandatory field, i.e. you must enter something in the field. If you do not want to restrict the file name, i.e. all file names should be found, then simply enter just an asterisk.

1.2. File Size

Here you can restrict the files to be searched by their size, by specifying a minimum and/or a maximum size. It is also possible to fill in only one of the two fields.

The size must be specified in bytes.

1.3. Modification Time

With the two fields after Last modified on:, you can restrict the search by the timestamp of the last modification. The following are possible as time specifications:
  • Date without time (DD.MM.YYYY)
  • Date with time without seconds (DD.MM.YYYY hh:mm)
  • Date with time with seconds (DD.MM.YYYY hh:mm:ss)

Strictly speaking, the point in time you enter is a time span, namely, depending on the kind of entry, a day, a minute, or a second. This time span is always to be understood as "inclusive", both for the start and the end point. So if you enter a date only in the first field, the files are found that were changed at some point during the specified day.

As an alternative to a specific date, you can also enter the keywords Today, Yesterday, and The day before yesterday. Upper/lower case does not matter here.

1.4. Contained Text

If you want to search for files that contain a certain text, enter the text you are looking for in the field after Contained text:. Only the files that contain the text are then found. If, in a file, the contained text is split up or separated by formatting or other bytes, the file will not be found.

If the search text contains non-ASCII characters (e.g. umlauts), the character set of the files to be searched must be known. For this purpose, JKCEMU checks the files for a possible byte order mark for UTF-8 and UTF-16. If one is present, the corresponding character set is used; otherwise, the local system character set. This also means that files without a byte order mark that were created with a character set other than the local system character set will probably not be found if the search text contains non-ASCII characters.

2. Search Result

The files and directories found are listed in the Search result: field. This also contains error messages marked in red, for example if a directory cannot be searched due to missing permissions. The text locations found are also shown, provided you have clicked the corresponding option.

If the search result is too large for you, you can select entries you no longer need and then remove them (menu item Edit → Remove Selected Entries from Search Result). A different menu item can be used to remove the red error entries. Removing entries from the search result, or clearing the entire search result, can also be done while the search is still running, and has no effect on the files or directories found themselves, i.e. they are not deleted as a result.

To use the files or directories found, select them and then call up the desired function in the File or Edit menu. You can also drag the files found out of the search result and into another window using drag&drop.

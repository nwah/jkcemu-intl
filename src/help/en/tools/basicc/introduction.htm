BASIC Compiler

General Information

The compiler is used to translate BASIC programs into machine code. The machine code programs generated this way can be started directly in the emulator or saved to a program file.

The BASIC compiler is characterized by the following capabilities:
  • 16-bit and 32-bit integer arithmetic
  • Floating-point arithmetic
  • String handling
  • Graphics support.
  • Support for structured programming using various kinds of loops and user-defined functions and procedures
  • Generation of fast and compact Z80 program code for the following computers (see target systems):
    • AC1
    • CP/M-compatible systems
    • HC900
    • Hübler-Grafik-MC
    • KC85/1...5
    • KC87
    • Kramer-MC
    • LLC2
    • Z1013
    • Z9001

Normally, the compiler generates standalone programs that are started with the appropriate command in the operating system. However, it is also possible to compile the BASIC program into a machine code subroutine (see compiler options). This allows the compiled program to be called from other programs with a CALL command.

BASIC Compiler

Constants

Constants contain a numeric value that cannot change during the run of the program. However, it is possible for the value of a constant to differ from one target system to another (e.g. with the colors), or from one compiler run to the next (e.g. with addresses).

With the exception of the mathematical constants, all constants have the data type Integer. The mathematical constants have the type Single.

1. Boolean Values

ConstantValueMeaning
FALSE 0 value for "false" (no bit set)
TRUE -1 value for "true" (all bits set)

2. Mathematical Constants

ConstantValueMeaning
DOUBLEPI 6.283185 double the circle constant 2π
HALFPI 1.570796 half the circle constant ½π
PI 3.141593 the circle constant π
EULER 2.718282 Euler's number

The mathematical constants have the data type Single.

Note: The advantage of the mathematical constants over specifying the respective numeric value directly is that the mathematical constants contain their respective value with the maximum possible precision that the data type Single offers. This eliminates any rounding errors that would otherwise result from converting a directly specified decimal number into the internal binary number.

3. Rounding Methods

These constants are used with the function ROUND and specify how to round when the value to be rounded lies exactly halfway between two possible result values.

ConstantMeaning
ROUND_HALF_DOWN round the magnitude down, i.e. towards zero
ROUND_HALF_EVEN round the magnitude to the nearest whole number
ROUND_HALF_UP round the magnitude up, i.e. away from zero

4. Colors

The constants for the colors are intended for use with the statements BORDER, COLOR, INK and PAPER. This means you do not need to know the concrete color numbers of the target system, at least for the eight primary colors, and can therefore write BASIC programs that work across platforms.

ConstantMeaning
BLACK code for the color black
BLINKING code for blinking,
BLINKING is only used in combination with a foreground color, e.g.:

 INK RED+BLINKING:  PRINT "I am blinking red";
 INK WHITE:  PRINT "white without blinking";
BLUE code for the color blue
CYAN code for the color cyan
GREEN code for the color green
MAGENTA code for the color magenta
RED code for the color red
WHITE code for the color white
YELLOW code for the color yellow

5. Graphics Pens

The constants for the graphics pens are used as a parameter for the PEN statement and are also described there.

ConstantMeaning
PEN_ERASER erase mode
PEN_NONE pen raised
PEN_NORMAL normal drawing mode
PEN_XOR XOR mode

6. Joystick

The joystick constants are used to evaluate the return value of the JOYST function. For this, the return value must be combined with the respective constant using AND.

ConstantMeaning
JOYST_LEFT joystick pushed left
JOYST_RIGHT joystick pushed right
JOYST_UP joystick pushed up
JOYST_DOWN joystick pushed down
JOYST_BUTTON1 action button 1 pressed
JOYST_BUTTON2 action button 2 pressed
JOYST_BUTTONS action button 1 or 2 pressed

7. Error Codes

The error code constants are used to evaluate the system variable ERR.

ConstantMeaning
E_CHANNEL_ALREADY_OPEN An attempt was made to open an I/O channel that is already open.
E_CHANNEL_CLOSED A statement or function for I/O was called on a channel that is not open.
E_DEVICE_LOCKED The I/O device is already in use and cannot be used multiple times at the same time.
E_DEVICE_NOT_FOUND The specified I/O device was not found. Either the device does not exist or is not ready, or the device is not supported for the target system, or the device name was misspelled.
E_DIGITS_TRUNCATED During the last calculation with the data type Decimal, decimal places were truncated because they did not fit into the data type (max. 7 decimal places). The result is therefore no longer mathematically exact.
E_DISK_FULL The file could not be opened for writing, or the output operation could not be performed, because the storage medium is full.
E_EOF An attempt was made to read past the end of the file.
E_ERROR A general or unspecified error has occurred.
E_FILE_NOT_FOUND The specified file was not found.
E_INVALID The operation is not permitted, or a parameter contains an invalid value.
E_IO_ERROR The I/O operation failed.
E_IO_MODE The operation is not possible with the mode with which the channel was opened. The error occurs, for example, when an attempt is made to read from an output channel or to write to an input channel.
E_NO_DISK The storage medium is not present, e.g. no floppy disk inserted or no USB storage device connected.
E_OK The statement or function in question was executed successfully, i.e. no error occurred. E_OK has the numeric value 0. This means an error can also be tested for without a comparison operator:

IF ERR THEN PRINT "Error"
E_OVERFLOW A numeric overflow has occurred.
E_PATH_NOT_FOUND The specified path was not found.
E_READ_ONLY An attempt was made to open a write-protected file, or a file on a write-protected storage medium, for writing.

9. System Constants

ConstantMeaning
GRAPHICSCREEN This constant is intended as a parameter for the SCREEN statement and contains the number of the graphics-capable screen. If the target system does not support graphics, the constant has the value -1.
LASTSCREEN the highest possible screen number that can be set with the SCREEN statement
TOP address of the first free byte behind the memory occupied or used by the compiled BASIC program

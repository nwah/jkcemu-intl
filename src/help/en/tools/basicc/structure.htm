BASIC Compiler

Program Structures

The BASIC language includes statements for controlling the program flow (structural statements) as well as statements that are used for actual data processing. This section describes the structural statements.

1. Branches

For branches, there is the statement IF. It can be used in single-line or multi-line form. For more specialized cases, where an expression must be tested against constant values, the statement  SELECT CASE is recommended. Further branching options are provided by ON...GOTO and ON...GOSUB.

2. Loops

The table shows the types of loops:

LoopRemark
DO ... LOOP infinite loop
DO ... LOOP UNTIL post-test loop
DO ... LOOP WHILE post-test loop
FOR ... NEXT post-test loop
WHILE ... WEND pre-test loop

All loops can be exited early with the EXIT statement.

A loop can also be implemented using the GOTO statement known from classic BASIC. However, since this does not correspond to structured programming, GOTO should be avoided wherever possible.

3. Subroutines

In classic BASIC, subroutines are implemented with the statements GOSUB and RETURN, which are also understood by the JKCEMU BASIC compiler. However, it is recommended to use the much more powerful user-defined functions and procedures instead. These allow BASIC programs to be structured far better, since you can pass arguments, use local variables, and, in the case of a function, also return a value.

4. Program End

The END statement is used to terminate a BASIC program.

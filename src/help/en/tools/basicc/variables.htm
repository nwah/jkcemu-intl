Variables

Variables are used to store numeric values or strings (character strings). Every variable has a name and a data type. You can choose the variable name freely. It must start with a letter and, provided it is longer than one character, may contain letters and digits from the second position onward. Upper and lower case are not distinguished. The variable name must not be a reserved keyword.

The data type determines what can be stored in the variable. String variables are limited to 255 characters.

1. Simple Variables and Arrays

There are simple variables and array variables (arrays, for short). Arrays consist of several array elements. The JKCEMU BASIC compiler supports arrays with up to two dimensions, i.e., the array elements can be arranged in one or two dimensions. The dimensions, or the indexes used to access an array element, are written in parentheses after the variable name (in this case also called the array name).

2. Global and Local Variables

Variables have a scope within which they are visible and therefore usable. The scope, and thus the visibility, can be global or local. Global variables are visible throughout the entire BASIC program, local ones only in the user-defined function or procedure in which they were declared using LOCAL. If a local variable has the same name as a global one, it hides the global variable, i.e., within the scope of the local variable, the global variable of the same name cannot be accessed.

3. Declaring Variables

Variables must be declared before they can be used. Declaring a variable means specifying its name and its type.

The JKCEMU BASIC compiler knows two kinds of variable declaration: implicit and explicit. Implicit variable declaration is familiar from classic BASIC and means that you simply use a variable. When the compiler (or, in classic BASIC, the interpreter) encounters a variable it does not yet know, it simply creates it. In the JKCEMU BASIC compiler, only simple integer and string variables can be declared implicitly. The data type is then derived from the name: if it ends with a $ character, it is a string variable, otherwise an integer variable.

With explicit variable declaration, the variables are introduced with the DIM or LOCAL statement. Long, Decimal and Single variables, as well as arrays, must be declared explicitly; integer and string variables may be. In the interest of a "clean programming style" and with an eye toward other modern programming languages, it is recommended to declare all variables explicitly, including integer and string variables.

4. Assigning and Reading Values

Simple variables, as well as the individual array elements of array variables, can be assigned a value and read again as often as desired. Assignment is possible with the statements LET, INPUT, LINE INPUT, PASSWORD INPUT and READ. To read the value stored in a variable, specify the variable name within an expression.

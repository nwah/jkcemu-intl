BASIC Compiler

Expressions

Expressions are combinations of literals (numbers and strings written in the BASIC program), variables, function calls, operators and parentheses that yield a numeric value or a string as their result. Expressions that yield a numeric value are numeric expressions. Expressions that yield a string are called string expressions.

1. Numeric expressions

Numeric expressions yield a numeric value with the data type Integer, Long, Decimal or Single.

1.1. Numbers

The compiler understands decimal numbers with and without a decimal point, hexadecimal numbers and binary numbers. Decimal numbers begin with a digit 0 to 9, hexadecimal numbers with &H and binary numbers with &B.

The data type of the number is determined automatically. If needed, however, you can also force a type by appending a letter:

Caution! If you do not force a data type, it can still happen that, for optimization reasons, the compiler internally generates a different data type. For example, when assigning a Long variable an Integer literal, the literal is internally compiled directly as Long, in order to avoid the call to a corresponding conversion routine that would otherwise be necessary at run time.

1.2. Variables

Variables are used in an expression to read the value stored in a variable. For array variables, a specific array element must always be specified, since an expression can only yield a single value. Access to a single element is done with an index, or a list of indexes, in parentheses following the array name.

1.5.1. Comparison operators

Comparison operators (=, <>, <, <=, > and >=) always yield an Integer value as their result, namely either 0 (comparison failed, all bits cleared) or -1 (comparison succeeded, all bits set). Because either all bits are set or all bits are cleared, the bitwise operators AND and OR as well as the bitwise negation NOT can also be used as logical operators for combining comparisons. The following example illustrates this:

10 A$="ABC"
20 B$="XYZ"
30 C=1
40 D=2
50 PRINT (A$<B$) AND (C<D)

Line 50 outputs -1. This comes about as follows: The subexpressions A$<B$ and C<D each yield the value -1, i.e. all bits are set. The AND operation between all bits set and all bits set remains all bits set, which represents the numeric value -1.

1.5.2. Mathematical operators

The mathematical operators are: + - * / ADD SUB MOD. If both operands have the same data type, the operation is also carried out with this data type. If, on the other hand, the operands have different data types, the operand whose type has the smaller value range is first converted to the data type of the other operand (automatic data type conversion). The result then has the data type with the larger value range.

The result must fit into the result data type. If this is not the case, a numeric overflow occurs and the program terminates with an appropriate error message.

The operators ADD and SUB, on the other hand, perform an Integer addition or subtraction without an overflow check. This is useful, for example, when calculating memory addresses. The following example illustrates this:

10 A=&H7F00
20 N=0
30 FOR I=0 TO 999
40 IF PEEK(A+I)=0 THEN N=N+1
50 NEXT
60 PRINT N

Starting at address 7F00h, the number of null bytes is to be counted in the following 1000 bytes. At address 8000h the program terminates with a numeric overflow, since the largest possible signed value of 32767 (7FFFh) has been exceeded. With the ADD operator, the program does not terminate:

10 A=&H7F00
20 N=0
30 FOR I=0 TO 999
40 IF PEEK(A ADD I)=0 THEN N=N+1
50 NEXT
60 PRINT N

Caution! Some BASIC dialects also have the operator ^ for exponentiation. The JKCEMU BASIC compiler does not support this operator, but offers the same functionality in the form of the function POW.

1.5.3. Bitwise operators

The operators AND, OR and XOR perform bitwise operations and are only possible with the data types Integer and Long. If both operands have the data type Integer, Integer is also returned. In all other cases, i.e. if at least one operand has the type Long, the entire operation is carried out as Long.

1.5.4. Shift operators

The operators SHL and SHR shift the 16-bit Integer or 32-bit Long value of the left operand as many bits to the left (SHL) or right (SHR) as specified by the right operand. Zero bits are always shifted in. Bits shifted out are lost. No overflow check is performed. The result has the same data type as the left operand.

1.6. Precedence rules

The various operators have different binding strength. Operators with a higher binding strength are executed before operators with a lower binding strength. Within the same binding strength, execution proceeds from left to right.

2. String expressions

String expressions are either a string literal (a string constant), a string variable, or the call of a string function. Concatenating string expressions with the plus sign is only allowed when assigning a string variable (the LET statement) and with the statements LABEL and PRINT.

Please read the notes on string handling.

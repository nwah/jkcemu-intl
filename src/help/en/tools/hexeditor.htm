Hex Editor

The Hex Editor lets you view and change files in their binary form.

1. Starting the Hex Editor

You open the Hex Editor in the emulator window via the menu Extra → Tools → Hex Editor.... However, it is also possible to open this tool with a file selected in the File Browser, or to start the Hex Editor as a standalone program without the emulator. For the latter, specify the option --he or --hexeditor on the command line when starting JKCEMU. Optionally, a file can also be specified after it, which is then opened.

If the Hex Editor was started without a file to open, you find yourself in New File mode. In this mode, you can create a new file by using Append Bytes at the End... and then saving.

2. Functions

The File menu contains the functions for opening and saving the file. You change the file contents using the functions in the Edit menu. Many functions require you to select a byte on, or starting from, which the function acts (see the section Jumping to a Position further below). Some functions also allow the selection of several bytes (see the section Selecting a Range further below).

Bytes are entered in a separate dialog window, in which you also specify the form in which the bytes are to be entered. If you choose 16-bit decimal numbers or 32-bit decimal numbers as the form, the toggle option between little endian and big endian becomes active. Little endian means that the low-order byte comes before the high-order byte. This is the byte order also found in the emulated systems. With big endian, on the other hand, the high-order byte comes before the low-order byte.

With the menu item Append File at the End..., you have the option of chaining several files together into one. Conversely, you can use Save Selected Bytes... followed by Remove Selected Bytes to split the open file into several files.

2.1. Overwriting Bytes Directly

As already indicated above, you change or overwrite data bytes by first clicking the first byte to be changed to select it, and then calling up the menu item Edit → Overwrite Bytes.... In addition, there is also the option of changing the data bytes directly in the display, by simply entering two hexadecimal digits, thereby setting the new value of the selected data byte. However, this direct input option can easily lead to accidentally overwriting the file's contents. For this reason, it is disabled by default. You enable this input option via the menu item Settings → Overwrite Bytes by Direct Input. This setting is saved along with the rest when saving a profile.

3. Jumping to a Position

You set the cursor to the desired position with a mouse click. However, you can also enter the desired position in one of the two fields in the Cursor Position area and press Enter.

4. Selecting a Range

You select a range by dragging the mouse with the mouse button held down, or by using the cursor keys while holding down the Shift key.

Another option, which is especially useful when selecting larger ranges, is provided by remembering a position: first click the first of the bytes to be selected and call up the menu item Remember Position. Then jump to the last byte to be selected and use the menu item Select up to Remembered Position.

5. Copying Selected Bytes

With this function, which you find in the Edit menu, you can copy the selected bytes as a hex string to the clipboard and then paste them from there, for example, into the dialog for entering bytes.

Memory Editor

The Memory Editor is used for viewing and changing the bytes in the emulator's working memory.

1. Displaying a Memory Range

In the upper area, the window contains two fields for entering the start and end address. Fill these in as hexadecimal values and choose the menu item File → Refresh. The corresponding range of the working memory is now displayed in the window.

You can also refresh by pressing the Enter key while the cursor is in the input field for the end address.

Caution! You always see the memory range as the microprocessor sees it at the time of the refresh. If the emulated system has several memory banks overlapping in that address range, you must make sure yourself that the correct bank is switched in.

2. Writing to a Memory Range

First, click with the mouse to set the cursor on the memory location you want to write to. Then choose the function Edit → Overwrite Bytes... in the menu. In the dialog that opens, enter the bytes to be written and press OK.

To position the cursor, you can also enter the desired address into one of the two fields in the Address area and press Enter.

Caution! If the emulated system has several memory banks overlapping in that address range, the bytes are written to whichever memory bank the microprocessor sees at the time of writing. You must make sure yourself that the correct bank is switched in.

2.1. Overwriting Bytes Directly

Besides the procedure described above for writing to the memory range, there is also the option of changing the data bytes directly in the display by simply typing two hexadecimal digits, thereby setting the new value of the selected data byte. However, this direct input option can easily lead to the memory range being overwritten by mistake. For this reason, it is disabled by default. You can enable this input option via the menu item Settings → Overwrite Bytes by Direct Input. When a profile is saved, this setting is saved along with it.

3. Copying Selected Bytes

With this function, which you find in the Edit menu, you can copy the selected bytes as a hex string to the clipboard and then paste them from there, e.g. into the dialog for searching for or overwriting bytes. To do this, select the desired bytes by dragging with the mouse button held down, or by pressing the cursor keys while holding down the Shift key.

Caution! The bytes to be copied are read directly from the working memory. If these bytes have since been changed in the meantime (e.g. by loading files or by the emulated system itself), bytes other than the ones shown in the Memory Editor are copied.

4. Font

The font for the data display can be changed in the JKCEMU Settings window, on the Fonts/Icons tab, under Font for code areas.

Hex File Comparator

The Hex File Comparator tool provides a hexadecimal display of the binary differences between files. It is built into JKCEMU to help you find out, for example, whether and how several versions of a program differ, when you have more than one version of it. This is intended to provide a way to recognize and distinguish, for example, original and patched versions of a program.

You can compare several files by adding them (see the File menu). As soon as at least two files have been added, they are compared and the result is shown.

To remove a file from the comparison again, select it and call up the function Remove File in the File menu.

By default, only a certain number of differences are shown. You can set the number of differences to be shown in the Settings menu. However, do not choose too large a value, since the comparison can then take a very long time, and the required main memory may also not be sufficient, which could cause JKCEMU to crash.

The maximum number of file differences to be shown is permanently saved when you save a profile in the Settings.

The Hex File Comparator can also be started as a standalone program without the emulator. To do so, specify the option --hd or --hexdiff on the command line when starting JKCEMU. In addition, files can also be specified after it, which are then opened in the Hex File Comparator.

The File Browser lets you load or open programs and files especially conveniently. While loading in the usual way with a file selection dialog requires many mouse clicks, the File Browser can stay open, so that a file can be selected at any time and loaded or opened with just a few mouse clicks. In addition, depending on the settings, hidden files are also visible, which is not the case with the JKCEMU file selection dialog.

Besides making it convenient to load files into the emulator, the File Browser also offers many of the functions of a file manager, such as copying files and directories, moving them (cut and paste), deleting them, etc.

1. View

The File Browser shows the file system on the left-hand side in a tree view. Using the entries in the Settings menu, you can specify how the files and directories are sorted and whether hidden files or directories should also be shown.

The right-hand side is used to display details. Between the two sides there is a divider that you can drag left and right. When you click a file, detail information is shown on the right-hand side. For an image file, you see the whole image, provided the file format is supported and the configured maximum file size for the preview has not been exceeded. For an archive file (TAR and ZIP), as well as for a directory, its contents are shown.

2. Drag&Drop

The File Browser can be used both as the source and as the target of a drag&drop operation, i.e. you can select a file, drag it with the mouse button held down into another window, and release it there. It is then up to the other window what happens with the file. The JKCEMU emulator window will, in such a case, load the file.

In the other direction, i.e. if you drag a file into the left-hand view of the File Browser and release it there over a directory, the file is copied or moved into that directory. It is also possible to drag a file out of a web browser into the File Browser, provided the web browser supports this. In that case, JKCEMU will download the file and save it in the directory in question.

Drag&drop can transfer not only a single file, but also several files as well as directories. However, it may be that the target window can only do something with a single file, but not with several files or with directories. For instance, it usually makes little sense to drag a directory into a text editor and try to open it there.

3. Loading and Starting Files

The File Browser's main task is to load files conveniently and, if applicable, also start them. The File menu offers various functions for this, the most important of which can also be found in the toolbar at the top of the window.

Caution! If the File Browser was started with the JKCEMU command-line option --fb or --filebrowser without the emulator (see Invocation and Command Line), nothing can be loaded into the emulator either. In that case, the menu items and buttons for loading into the emulator are not visible, and double-clicking does not perform a load either.

3.1. Load into Emulator With...

With this function, the dialog with the load options is always shown before the selected file is loaded. This lets you, for example, load the file to an address other than the one specified in the file.

3.2. Load into Emulator

With this function, the selected file is loaded into the emulator's main memory without prompting. However, this requires that the file's format also has load addresses. If that is not the case, a load address must be specified. In that case, the dialog with the load options appears after all.

3.3. Start in Emulator

If the selected file contains an executable machine code program and a start address, the file is loaded without prompting and the program is started.

3.4. Double-Click

Double-clicking a file performs the action that makes sense for that file. A text file is opened in the Text Editor, an image file is shown in the Image Viewer (if the file format is supported), and a sound file is played (if the file format is supported). If JKCEMU does not know what to do with the file, the operating system is asked to open the file.

4. Cutting, Copying, and Pasting

Using the Edit menu as well as the context menu, you can cut, copy, and paste files and directories. For this, the operating system's clipboard is used (if available), i.e. this also lets you transfer files back and forth between the File Browser and other windows or programs.

Caution! The Cut function only works within the File Browser. If you cut a file in the File Browser and paste it into a different program, the file is copied, not moved.

As a special feature, the File Browser also offers the option of copying just the full names of files and directories, both as plain text and in the form of a URL.

6. Further Functions

Besides loading or opening files, the File Browser also offers further functions, such as creating directories, renaming and deleting directories and files, calculating checksum/hash values, packing and unpacking, and setting the modification time to any value. You find all these functions in the File menu.

7. Keyboard Operation

The File Browser can also be operated conveniently and quickly with just the four cursor keys. Directories are expanded and collapsed with the Left and Right keys. The Enter key has the same function as a double-click.

8. Settings

In the Settings menu, you can adapt the File Browser to your needs. These settings, the position of the divider between the tree view and the preview, and the window size and position can also be permanently saved in a profile. You do that in the separate Settings window.

8.1. Monitoring Displayed Directories for Changes

If the option Monitor Displayed Directories for Changes is switched on, the display is automatically updated as soon as there are changes in the directories. The technical implementation depends on the operating system and the file system. If this directory monitoring causes unpleasant effects or other problems for you, then please switch the option off and save the settings in a profile (preferably in the standard profile), so that the option stays permanently switched off.

Adapting JKCEMU to Your Own Needs

In the Settings window, the emulator offers a wide range of configuration options with which you can adapt it to your own needs. Not only can you choose between different computer types, but for some computer types you can also specify various hardware configurations to be emulated. Other settings affect the appearance and behavior of the emulator itself. Furthermore, the sizes and positions of the currently open windows are also saved in the profiles.

After you have configured JKCEMU according to your wishes and applied the settings, you can save your configuration in the form of a profile. To do this, give the profile a name. You can create as many profiles as you like and save each one under a different name.

Caution! The name of a profile must follow the conventions of a file name without a path and without a file extension. On some operating systems (e.g. Linux and Unix), you must also pay attention to correct upper/lower case.

Of course, you can also reactivate the settings you have saved in a profile. To do this, you must apply the profile. You do this in the main window, menu Extras, menu item Apply Profile....

If you save a profile under the name "standard", it has a special meaning. This profile is automatically applied when you start the emulator. Therefore, save the settings you use most often in the "standard" profile.

However, you can also apply any other profile right at startup. To do this, specify the name of the profile as an argument on the command line used to invoke JKCEMU. This allows you, for example, to create several shortcuts to the emulator on your computer's desktop, specifying a different profile name as the argument for each shortcut. This way, you can start JKCEMU quickly and conveniently with different configurations.

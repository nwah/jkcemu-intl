Kramer-MC: Editor

The editor has a command mode and an input mode. After starting it (monitor command T), you are in command mode.

The address range 4000H to 7FFFH is used as text storage. A different text storage area can also be set with the A command.

Commands

CommandFunctionSyntax
A(sign) Text storage assignmentA nnnn (CR)
D(isplay) Display a number of n lines, advancing the line counter Dn (CR)
E(dit)Text input modeEn (CR)
G(o) Advance the line counter forward by n lines Gn (CR)
I(nput) Assign input channel IT, IL or IU
L(ist) Assign printer channel LT, LL or LU
0(utput) Assign output channel OT, OL or OU
P(rint) Output all lines on the list channel P
Q(uit)Return to the monitorQ


Editor Control Characters

KeyFunction
BS Cursor left, correction possible by overwriting
DELClear the content of the display line
LP Adopt the line into the text buffer, display the next line from the buffer
CR Adopt the line into the buffer, leave the E command
Control D Duplicate the second-to-last line into the working line
Control Z Adopt the line into the buffer, start a new line
Control X Delete the character above the cursor, shift the rest to the left
Control S Insert a character above the cursor, shift the rest to the right


Editor Error Messages

E1Command error
E2Text buffer full
E3Parameter error

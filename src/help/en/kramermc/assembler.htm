Kramer-MC: Assembler

By default, the assembler expects the source code to be translated in the text buffer of the editor, i.e., you write the assembler program with the editor. Since the assembler requires about 8k of RAM, only short programs producing at most 1 KByte of object code can be created, due to the memory layout.

If the screen is assigned as the listing device (LT), the listing appears 16 lines at a time. After pressing the space bar, the next 16 follow.

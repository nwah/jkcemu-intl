NANOS

NANOS is a modular system developed by the Ingenieurhochschule für Seefahrt Warnemünde/Wustrow, based on the K1520 bus system that was widely used for industrial applications in the GDR. NANOS thus does not describe a specific computer, but only a set of boards (modules) from which a computer could be assembled. Several operating systems were available for such a computer.

JKCEMU emulates the most important NANOS boards as well as some more recent developments.

1. Emulated Hardware

JKCEMU emulates the most important NANOS boards as well as some more recent developments.

1.1. ZRE Board

The Zentrale Recheneinheit 1 (ZRE 1, central processing unit) board is emulated. It contains the U880 microprocessor, 2 or 4 KByte of ROM (starting at address 0000h), 1 KByte of RAM (1000h-1400h), and a PIO at I/O base address 00h. Due to incomplete address decoding, the PIO can also be addressed up to I/O address 7Fh. Writing a 0 to bit 7 of PIO port B disables the memory on the ZRE board.

1.2. Screen Control

Depending on the setting, the following is emulated:
  • Video 2 screen control with 64x32 characters
  • Video 3 screen control with 80x24 characters
  • Video 3 screen control with 80x25 characters
  • Heiko Poppe's color graphics card, switchable between 64x32 and 80x24 characters

In all variants, the video RAM begins at address F800h.

Caution! The Video 3 screen control is emulated in the configuration with 8-bit characters. The configuration selectable on the original, which uses bit 7 for cursor control and thus only allows 7-bit characters, is not emulated.

1.3. 256 KByte DRAM

The memory board is divided into 4 banks of 64 KByte RAM each. One bank is used as working memory (selected via bits 4 and 5 of output address C2h). The other banks are used as a RAM floppy. They are accessed through a 256-byte window in the address range F700h to F7FFh.

1.4. IO Board

The emulated IO board contains:
  • 2 PIOs at I/O base addresses 80h and 88h
  • an SIO at I/O base address 84h
  • a CTC at I/O base address 8Ch

1.5. Cassette Interface

The cassette interface is emulated as follows:
  • Input: ZRE PIO port B bit 5
  • Output: ZRE PIO port B bit 6

1.6. Floppy Disk Controller

The Floppy Disk Controller is emulated as follows:
I/O AddressMeaning
92h Clock frequency, terminal count, and motor control:
  • Bit 0: FDC clock frequency (0: 8 MHz, 1: 4 MHz)
  • Bit 1: terminal count
  • Bit 2: precompensation (has no effect in JKCEMU)
  • Bits 3 to 6: motor control signals (have no effect in JKCEMU)
94h main status register
95h data register

1.7. GIDE

GIDE is optionally emulated at I/O base address D0h.

1.8. K1520 Sound Card

A K1520 sound card is optionally emulated at I/O base address E0h.

Caution! The K1520 sound card is normally operated in the I/O address range 38h to 3Fh. Since this range is blocked by the ZVE card in the NANOS, the I/O address range E0h to E7h is used instead.

I/O AddressMeaning
E0hselect or read sound register
E1hwrite sound register
E4hCTC channel 0
E5hCTC channel 1
E6hCTC channel 2
E7hCTC channel 3

1.9. KCNet

A KCNet card is optionally emulated at the first PIO of the IO board (I/O base address 80h).

1.10. USB Connector

A USB connector (Vinculum VDIP module) is optionally emulated at the second PIO of the IO board (I/O base address 88h).

1.11. Keyboard

There is no dedicated NANOS keyboard and thus no uniform keyboard interface. The keyboard was simply connected to one of the numerous interfaces available. JKCEMU emulates three different variants of the keyboard connection:
  • ZRE board: PIO port A, handshake with Ready/Strobe
  • ZRE board: PIO port A, strobe on bit 7 (bit 7 is set while a key is pressed).
  • IO board: SIO channel A

1.12. Printer

A printer is emulated, connected to the IO card, SIO channel A, with hardware handshake (CTS).

2. Software Contained in ROM

  • boot ROM for booting NANOS 2.2
  • boot ROM for booting EPOS 2.1

Both boot ROMs each contain a bootstrap loader that, after power-on or reset, tries to boot from the first drive. For this reason, you must insert a floppy disk into the first emulated drive and then trigger Power On or RESET.

Caution! To boot other operating systems, it may be necessary to fill the boot ROM with different content. This is possible in the Settings by loading an appropriate ROM file.

3. Included Disk Images

For the NANOS emulation, JKCEMU includes the following disk images:
  • NANOS 2.2 Boot Disk
    To use this disk image, you must set the following configuration:
    • Video 3 screen control with 80x25 characters
    • keyboard on ZRE PIO port A with Ready/Strobe handshake
    • boot ROM for NANOS 2.2


  • EPOS 2.1 Boot Disk (64x32 characters)
    To use this disk image, you must set the following configuration:
    • Graphics:
      • Video 2 screen control with 64x32 characters, or
      • color graphics card, switchable between 64x32 and 80x24 characters
    • keyboard on ZRE PIO port A with strobe on bit 7
    • boot ROM for EPOS 2.1


  • EPOS 2.1 Boot Disk (80x24 characters)
    To use this disk image, you must set the following configuration:
    • Graphics:
      • Video 3 screen control with 80x24 characters, or
      • color graphics card, switchable between 64x32 and 80x24 characters
    • keyboard on ZRE PIO port A with strobe on bit 7
    • boot ROM for EPOS 2.1

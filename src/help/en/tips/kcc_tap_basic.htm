Extracting a KC-BASIC Program from a KCC/KC-TAP File

KC-BASIC programs are often not stored in a KC-BASIC file format, but in a KC system format. This is usually done to make the program self-starting with the help of a small machine code routine. A special case here is the KCB format, since this is supported directly by JKCEMU. In all other cases, proceed as follows:
  1. In the Settings, set a KC or a Z1013 as the emulated system.
  2. Load the KC system file into the emulator. The BASIC program is now in memory starting at address 0401, where the ROM BASIC expects the BASIC program. You can now use the BASIC program in the ROM BASIC interpreter or display it in the Text Editor.
    However, if you want to make the program available for RAM BASIC, you still need to carry out the last two steps:
  3. Save the BASIC program via the menu File → BASIC Program → Save... as a KC-BASIC program file.
  4. Now load the file into memory, specifying the load address 2C01 for RAM BASIC in the Load Options.

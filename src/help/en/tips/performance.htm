Tips & Tricks

Improving Performance

Problem

JKCEMU reacts sluggishly, the screen output is very jerky, the emulated clock frequency is below the one specified in the settings, and the CPU is fully loaded at 100%.

Solution

First you should check whether other programs are running on your computer that use too much processing power or too much memory. Please close these programs first.

If that does not help, you can try to minimize the processing power required by JKCEMU:
  • If an HC900 or KC85/2..5 is currently being emulated, go to the KC85 Settings, tab Miscellaneous, and disable the option Emulate Screen Control Timing.
  • The processing power required is higher when JKCEMU has to scale the screen output. Set the view to 100% so that no scaling is needed.
  • In the Settings, section Screen Output, increase the value for the refresh cycle. In that case the screen output is updated less often. This does make the screen output somewhat less smooth, but it also saves processing time.
  • Disable the audio functions.
  • In the Settings, reduce the speed of the emulated system.

Tips & Tricks

Loading Files Stored on Magnetic Tape

Preliminary Remarks

In order to load files stored on magnetic tape, they must be playable back from the tape in sufficiently good quality. This is of course more difficult the older the recordings are, since quality degrades over time. This in turn can lead to errors when reading the data back in. You should therefore be patient and not give up after the first failed attempt.

Requirements

  1. You must connect the magnetic tape device (e.g. a cassette recorder) to the line-in or microphone jack of the computer running the emulator.
  2. You need software in the emulator that can read the format in which the files were stored on the magnetic tape. The operating systems and monitor programs included in JKCEMU offer the ability to load machine code programs stored in the respective standard format.


Procedure

  1. Connect the magnetic tape device to the line-in jack, or, if that is not available or the signal level is too low, to the microphone jack of the computer running the emulator. Suitable cables and adapters are available from specialty retailers.
  2. Use the volume control or a mixer to make sure that the playback from the magnetic tape device is audible on the computer running the emulator with slight overdrive.
  3. In the emulator, enter the command to load the file, but do not press ENTER yet.
  4. Activate the function Read Audio Data from Sound System.
  5. Start playback on the magnetic tape device.
  6. As soon as you hear the synchronization tone at the beginning of the file to be loaded, press the ENTER key. This starts the actual loading process.
  7. After the file has been loaded, deactivate the audio function and, ideally, immediately save the memory range you just loaded.


Notes on Read Errors

If loading causes problems, try the following tips:
  • Check whether the audio data is actually reaching the emulator (see the level meter in the Audio/Tape window). Use the volume control or a mixer to increase the input level of the line-in or microphone input. The input signal should be slightly to noticeably overdriven.
  • Check whether the emulation speed specified in the Settings matches the speed at which the file was stored on the tape.
  • Switch between the left and right channel, especially if the tape is being played back on a stereo cassette recorder.
  • Connect the magnetic tape device to a different audio input (e.g. switch between the line-in and microphone jack).
  • Change the speed of the emulator to a value about 10 to 20 percent lower or higher. This is particularly useful if the loading routine does not recognize the synchronization tone, and therefore not even the first block. The playback speed may differ too much from the speed at which the tape was recorded.
  • Try different sample rates.


If these tips do not lead to success, a real computer can be of great help:
  1. First load the file into the real computer. Due to the different hardware, the chances of success are better.
  2. Connect this computer to the audio input of the computer running the emulator.
  3. Start the load in the emulator as described above.
  4. On the connected computer, save the file so that the data is transferred directly to the computer running the emulator.


Another option is to play the file on the magnetic tape device and record it as a sound file using the operating system's tools. You then read this sound file into JKCEMU (see also Loading a Program Contained in a Sound File). This approach is particularly useful if your computer's processing power is not sufficient to maintain the emulation speed while reading the data in. This is the case when the emulated clock frequency shown in the status bar is significantly lower than the one specified in the settings.

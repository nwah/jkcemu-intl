Tips & Tricks

Loading a Program Contained in a Sound File

Problem

A program stored on magnetic tape has already been transferred to the computer and is now available as a sound file. The program contained in this sound file is now to be loaded into the emulator.

Procedure

  1. In the emulator, enter the command to load the file, but do not press ENTER yet.
  2. Activate the function Read Audio Data from Sound or Tape File. You will then be asked to select the sound file.
  3. Depending on the emulated system, i.e. depending on how the cassette recorder connection is queried, confirming the file selection starts reading the sound file. Now press ENTER so that loading of the program contained in the sound file also begins.
  4. Once the sound file has been fully processed, the audio function is deactivated automatically.


Notes on Read Errors

If read errors occur, the same notes apply accordingly as under Loading Files Stored on Magnetic Tape.

Reading Synthetically Generated Sound Files

If you read in a sound file that was generated by the emulator itself, it can happen that loading does not end, even though the sound file has been fully processed. In this case, simply a few final phase changes are missing. To fix this, activate the audio function once more with the same sound file (Read Last Sound or Tape File Again). Once the first phase changes have been read, the loading process ends, and you can deactivate the audio function again.

The cause of this phenomenon does not lie in a fault of the emulator, but in the way the loading routines are programmed. Under certain circumstances, they expect a few more phase changes than the saving routine generates. The missing phase changes are not a problem on a real computer, since they are supplied anyway by natural noise alone.

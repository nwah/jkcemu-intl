Directory Selection Dialog

In some places, selecting a directory is possible or even required. When you trigger such a function, a directory selection dialog appears. Open the corresponding subdirectories in it until you reach the desired directory, select it, and click Select.

There are operating systems that show the user a file system view that does not correspond to the physical file system structure. Such a user view can, for example, contain directories such as Libraries or Computer, or also directory names translated into the local language. If both the operating system and the Java runtime environment support such a user view of the file system, the directory selection dialog can also display both views. In that case, there is a checkbox below the directory tree, Show physical file system structure, with which you can switch between the two views. If this checkbox is not present, no user view is available either, and the physical file system structure is always displayed.

Printing

JKCEMU offers several ways to print. You can, for example, print help pages or the text currently shown in the Text Editor. A special topic is printing within the emulated systems, i.e. the emulation of a printer. This is covered here.

1. Printing in the Emulated Systems

Some systems offer a hardware printer connector (possibly also as an add-on module). This connector is reproduced by JKCEMU.

Frequently, a software interface was also defined that application programs could use for printing. The data connection from this software interface to the actual printer connector is handled by a driver, which usually has to be loaded separately. JKCEMU can also intercept the system calls made to this software interface, so that no special driver needs to be loaded in the emulator.

You can disable the interception of system calls for printer output in the settings.

1.1. Printing and Print Jobs

The printer is emulated in such a way that the bytes sent to the printer are first collected in the form of print jobs. You can save these print jobs, open them in the Text Editor, and of course also print them on paper. To do so, call up the function Print Jobs in the Extras menu of the JKCEMU main window. You manage the print jobs in the window that opens.

1.2. Managing Print Jobs

A new print job is created with the first data byte that a program outputs for printing. This print job is now active, i.e. all further data bytes go into it.

Since the printer emulation does not know when the application program has finished printing, the print job is usually not closed automatically. You must therefore do this manually. In certain cases, e.g. on a RESET, an active print job is, however, also closed automatically.

You can print or save print jobs, and open them in the Text or Hex Editor. If you no longer need a print job, e.g. because you have already printed it on paper, you can also delete it. You will find all these functions in the JKCEMU Print Jobs window, in the File menu.

With the function Print Options... you set the font size used for printing. You also specify whether the page number should appear.

1.3. Character Set

To display a print job in the Text Editor or print it on paper, the character set underlying this print job must be known. For this purpose there is the Character Set menu. This menu thus corresponds to the character set setting that used to be made directly on the printer.

When converting the print bytes into characters, bytes for which there is no equivalent in the selected character set are ignored. These bytes, or characters, are then missing from the displayed or printed text.

When a print job is opened in the Hex Editor or saved, the print job is not changed, i.e. in that case the selected character set does not matter.

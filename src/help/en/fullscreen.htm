Full Screen Mode

JKCEMU offers a full screen mode that, within certain limits, is meant to convey an "8-bit feel". The menu, and thus also most of the functions that can be called up through it, are not available (which, after all, you did not have on the original 8-bit computer either). Only the context menu gives you access to the most important functions, such as loading and saving programs and RESET. Access to the emulated peripheral devices as well as switching back to normal window mode (turning off full screen mode) is also possible via the context menu.

Caution! JKCEMU tries to fill the full screen as much as possible. To do this, provided the screen resolution allows it, the screen output of the emulated system is enlarged accordingly. However, this costs computing time, especially when the emulated system reproduces the timing behavior of the screen output (e.g. with KC85/2..5 and KC compact emulation of interrupts synchronous to the screen refresh). In such cases it can happen that the emulator requires more computing power than your computer can provide. JKCEMU will then feel sluggish. In that case, there is nothing else you can do but turn off full screen mode again via the context menu.

Caution! At the system level, no true full screen mode is set; instead it is only simulated with a maximally sized window without a border. This has the advantage that, if needed, programs running in the background can easily be brought to the foreground. However, there are also operating and window systems on which a taskbar, if present, cannot be covered by any window. On such systems the taskbar is then always visible.

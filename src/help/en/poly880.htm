Poly-Computer 880

The Poly-Computer 880, sometimes also written Polycomputer, is a learning computer with a 7-segment display and a hexadecimal keyboard, manufactured by VEB Polytechnik Karl-Marx-Stadt (today Chemnitz). As a special feature, the Poly-Computer offers a hardware single-step mode in which even the individual clock cycles of the microprocessor can be tracked. LEDs display the signals of the address, data, and control bus. However, this hardware single-step mode, and thus the display of the bus signals, is not emulated by JKCEMU.

1. Emulated Hardware

  • 2 KByte ROM in the address range 0000-03FF and 1000-03FF
  • 1 KByte RAM in the address range 4000-43FF
  • 8-digit 7-segment display
  • hexadecimal keyboard with additional function keys
  • cassette recorder connector
  • optional:
    • 32 KByte RAM expansion (8000h-FFFFh)
    • ROM 2 (2000h-23FFh)
    • ROM 3 (3000h-33FFh)
Due to incomplete address decoding, except for the optional RAM expansion, the individual ROM and RAM memory ranges are each visible four times in succession, i.e. you also see X000-X3FF in X400-X7FF, in X800-XBFF, and in XC00-XFFF, where X stands for 0...4.

1.1. Keyboard

The table shows how the keys of the Poly-Computer are mapped to the keys of the emulator computer's keyboard:
Poly880 Key Key in JKCEMU Meaning
BACK - or BackSpace previous address
EXEC X or Enter execute action
RES Escape RESET
FCT F1 function
GO G start program
REG R register
STEP S single-step mode
MEM M display/change memory
0...9, A...F 0...9, A...F address/data entry
CYCL single step (one clock cycle) in hardware single-step mode,
not emulated by JKCEMU
MCYCL enable hardware single-step mode,
not emulated by JKCEMU

(On the original, this also disables hardware single-step mode, which JKCEMU does not emulate anyway.)

Caution! For simplicity, Escape triggers RESET without a confirmation prompt, even if the confirmation prompt is enabled for this in the settings.

1.2. Hardware Single-Step Mode

On the original, there is a hardware single-step mode with which you can execute the individual clock cycles of the microprocessor step by step. JKCEMU does not emulate this hardware single-step mode. However, the software single-step mode that also exists is emulated (STEP key), which is used to execute complete machine instructions step by step.

1.3. Cassette and Sound Output

You can listen to the sound signals output at the emulated cassette recorder connector (PIO 1, port B, bit 0) in the Audio/Tape window on the Tape Output tab, or record them and save them to a file. The Speaker tab is responsible for the sound signals output via PIO 1, port B, bit 2 (speaker connector).

2.1. Notes on Operating the Monitor Program

2.1.1. Displaying/Changing Memory Cells

RES (Escape) → MEM (M) → <address> → EXEC (Enter) [ → <value> → EXEC (Enter) ]

Each time you press the EXEC (Enter) key, the next memory cell is displayed.

2.1.2. Displaying/Changing Registers

RES (Escape) → REG (R) → <register selection> [ → EXEC (Enter) → <high value> → EXEC (Enter) → <low value> → EXEC (Enter) ]

After pressing REG (R), you select the desired register pair by pressing a specific key. The following assignment applies:
KeyRegister Pair
0AF
1BC
2DE
3HL
4AF'
5BC'
6DE'
7HL'
8I and status of the EI flip-flop
9IX
AIY
BSP
CPC

If you want to change the register contents, press EXEC (Enter), enter the value of the high-order register, press EXEC (Enter) again, then enter the value of the low-order register and press EXEC (Enter) once more.

2.1.3. Starting a Program

RES (Escape) → GO (G) [ → <start address> ] → EXEC (Enter) [ → <breakpoint> ] → EXEC (Enter)

The start address and the breakpoint can be omitted. If the start address is omitted, the value currently stored for PC in the register save area is used.

2.1.4. Single-Step Mode

RES (Escape) → STEP (S) [ → <address> ] → EXEC (Enter)

This command executes the instruction at the specified address and then halts again. The address can be omitted. In that case, the value currently stored for PC in the register save area is used.

2.1.5. Port Input

RES (Escape) → FCT (F1) → 0 → <port address> → EXEC (Enter)

Each time you press the EXEC (Enter) key, the specified input port is read and the value is displayed.

2.1.6. Port Output

RES (Escape) → FCT (F1) → 1 → <port address> → EXEC (Enter) → <value> → EXEC (Enter)

After pressing the EXEC (Enter) key the first time, you enter the value to be output, which is then written to the output port when you press EXEC (Enter) a second time. You can now enter further values as often as you like, each of which is likewise output on the port by pressing EXEC (Enter).

2.1.7. Moving a Data Range

RES (Escape) → FCT (F1) → 2 → <destination address> → EXEC (Enter) → <source address> → <length> → EXEC (Enter)

This command moves a data range to another address. Strictly speaking, the data is not moved, but copied. The source and destination ranges may overlap. After the move, an F for "finished" appears in the display.

2.1.8. Filling a Data Range

RES (Escape) → FCT (F1) → 3 → <start address> → EXEC (Enter) → <length> → EXEC (Enter) → <value> → EXEC (Enter)

2.1.9. Loading a Data Range from Tape

RES (Escape) → FCT (F1) → 4 → <start address> → EXEC (Enter) → <end address> → EXEC (Enter) → EXEC (Enter)

After entering the end address, you must press EXEC (Enter) twice before loading begins. After loading has finished, an F appears in the display.

2.1.10. Saving a Data Range to Tape

RES (Escape) → FCT (F1) → 5 → <start address> → EXEC (Enter) → <end address> → EXEC (Enter) → EXEC (Enter)

After entering the end address, you must press EXEC (Enter) twice before saving begins. After saving has finished, an F appears in the display.

3. Miscellaneous

3.1. Loading External ROM Files

On the original Poly-Computer 880, the data lines are inverted, i.e. the bytes in the ROMs are correspondingly inverted as well. If you want to load such ROM contents, JKCEMU needs to know whether the ROM files are inverted in the same way as the original. For this purpose, the Settings provide the option ROM bytes are inverted. You must set this option correctly in every case as soon as you load an external ROM file! This option applies equally to all loaded ROM files.

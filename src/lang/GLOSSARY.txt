JKCEMU - Terminology glossary (German -> English)
=================================================

Encoding of this file: UTF-8.

Binding terminology for the translation catalogs in this directory.
The German terms are written exactly as they appear in the catalogs,
including umlauts, so that you can search for them.

If you translate into a language other than English, use the English
column as the reference meaning - it resolves the German terms that are
ambiguous out of context.


1. House rules
--------------

  - Menus, buttons, tab titles, check boxes, labels: Title Case.
    "Save As...", "Find Next", "Floppy Disk Station".
  - Dialog messages and status texts: sentence case, full sentences,
    keep the final punctuation of the German.
  - Keep a trailing "..." on any command that opens a further dialog.
    The German uses this consistently and so does English.
  - German addresses the user formally ("Sie"). In English use plain
    "you".  "Möchten Sie ... ?" -> "Do you want to ... ?"
  - Keep leading and trailing spaces. Several texts are fragments that
    are joined with other text at runtime.
  - Keep placeholders {0}, {1} unchanged; see TRANSLATING.txt.


2. Terms that are easy to get wrong
-----------------------------------

These are the ones worth checking twice. The wrong choice is listed so
you can recognise it.

  Marke               -> label            (assembler label)
                         NOT "mark", NOT "brand"

  Anweisung           -> statement        in the BASIC compiler
                      -> instruction      in the assembler
                         Check the source reference shown by Poedit:
                         programming/basic/... or programming/assembler/...

  Löschen             -> Delete           for files, entries, images
                      -> Clear            for a log window or an input field

  Einfügen            -> Paste            in an Edit menu
                      -> Insert / Add     everywhere else

  Erweiterung         -> extension        for a file name suffix
                      -> expansion        for a hardware expansion

  Spur                -> track            (floppy disk)
                         NOT "trace"

  Reassembler         -> Disassembler     the German word is a Germanism;
                         "Disassembler" is the established English term

  Testmonitor         -> Debugger         the author's older name for it

  Zeichensatz         -> character set    the character ROM of the
                         emulated machine. Only use "font" where a host
                         GUI font is meant.

  Symbol              -> icon             in "Große/Kleine Symbole"
                         (Large/Small Icons)

  Bis Rücksprung      -> Step Out         literally "until return"

  Seite               -> page             both for memory banking and for
                         help pages

  Anschluss           -> port             hardware
                      -> connection       network

11. Two typos in the German originals
-------------------------------------

The German source contains two spelling mistakes. Translate them
correctly; do not reproduce the mistake.

  "Hex-Dateivergeicher"                should be Dateivergleicher
                                       -> "Hex File Comparator"

  "Statusmeldungen in der Taskleise"   should be Taskleiste
                                       -> "... in the taskbar"
